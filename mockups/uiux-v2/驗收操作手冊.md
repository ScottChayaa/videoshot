# videoshot · 驗收操作手冊

> 對象：測試人員
> 環境：Android 手機直式（寬約 360–412dp）；另請至少開一次平板寬度
> 依據：[現行規格](../../docs/superpowers/specs/2026-09-10-videoshot-app-design.md)（含 2026-09-01 的 UI 決定，以及第六節最後的「UI 與原型的差異」）；
> [實作計畫](../../docs/superpowers/plans/2026-09-11-videoshot-android-實作計畫.md)的驗收條件引用本手冊的原文。
> **視覺的權威是 app 的共用元件**（開發測試版的元件總覽頁，列出每個元件的各種狀態）；
> `mockups/uiux-v2/` 的 HTML 原型是最初的視覺來源，現在只是歷史參考，兩者不一致時以 app 的元件為準。

**本手冊描述的是目標狀態。** 驗收對象是 **Android app**，所有條目都要驗。
開發測試版另有 `pnpm compare`（原型與實機並排截圖）可輔助對照；原型（`pnpm mock`，開 <http://localhost:8231/uiux-v2/login.html>，
原型保留登入頁作為入口，app 沒有登入）不再是驗收對象。標 **〔app〕** 的條目是只有 app 才有的行為。

標示 ⏳ 的是尚未確認的條目，驗收時先不計成敗。

## 零、先看整體（不必操作）

- [ ] **底部導覽有文字**：首頁／查詢／取圖／分類／帳號，五個項目都是圖示＋文字。
- [ ] **底部導覽的「取圖」格與帳號格**〔app〕：「取圖」格是主色實心方塊（選中與否都是）；帳號格在連結 Google 之後，圖示換成頭像字母（顯示名稱的第一個字）。
- [ ] **紅色只用在破壞性動作**：只有「刪除」「中斷連結」這類動作是紅的，主要動作一律是主色。
- [ ] **間距與字級有尺標**：間距只用 4/8/12/16/24/32，字級只有 6 階。
- [ ] **不跟系統的深色模式走**：app 沒有深色模式，打開就是設定好的色系。把手機切成深色再開 app，畫面與系統列圖示都跟淺色時一樣。
- [ ] **輔助操作**：開 TalkBack 走一遍首頁，每個可點的東西都唸得出名稱；接上實體鍵盤時，用 Tab 走得到每個可點的東西、看得到焦點框。
- [ ] **平板寬度**：600dp 以上會加欄。（桌機版面不做）

## 一、備份與還原〔app〕

> app 不需要登入。Google 帳號只用來把圖庫備份到使用者自己的 Google Drive。

- [ ] **不連結 Google 也能完整使用**：帳號頁顯示「尚未設定備份」與【連結 Google 帳號以啟用備份】。
- [ ] **授權範圍很小**：連結時的 Google 授權畫面只要求「app 自己的設定資料」，不該出現「查看／管理你所有的 Drive 檔案」。
- [ ] **手動備份**：帳號頁【立即備份】→ 完成後顯示「上次備份：剛剛」與檔案大小。
- [ ] **自動備份**：有新增或修改、連著 Wi-Fi 的情況下，隔天不必開 app，帳號頁的「上次備份」也會更新。
- [ ] **全新安裝的第一個畫面**：可選【從 Google Drive 還原】或【全新開始】。還原清單顯示最近 3 份備份的日期、張數、來源裝置。
- [ ] **還原後立刻能用**：圖資、標籤、地點、資料夾、截圖都在；storyboard 縮圖先顯示該影片的封面，之後逐漸換成正確的畫面。
- [ ] **覆蓋前說清楚**：從帳號頁還原時，確認框說得出「本機的 N 張收藏會被取代，未完成的取圖草稿也會捨棄」。
- [ ] **還原失敗不會壞掉**：還原途中關掉網路 → 原本的資料完好，不會變成半套。
- [ ] **回填看得到進度**：帳號頁顯示「縮圖回填中 320 / 1,200」；只在 Wi-Fi 下進行，進度卡片上有【用行動網路繼續】。
- [ ] **抓不回來的縮圖**：已刪除或轉私人的影片，它的縮圖顯示中性的預留圖並標影片秒數，不是破圖；
      帳號頁顯示「無法取回 N 張」，有【稍後重試】與【刪除這些收藏】。
- [ ] **中斷連結**：【中斷連結】在帳號頁最底、用破壞性樣式。

## 二、首頁

- [ ] **每個月份欄數都一樣**，不隨當月張數改變；手機預設每列 4 張，〔app〕帳號 › 縮圖可改成 2／3／4 張，重開 app 仍記得。
- [ ] 〔app〕縮圖**直角**、左右**貼齊螢幕邊緣**；月份標題與標籤列左右仍有留白。
- [ ] **卡片上只有縮圖，沒有描述文字**；縮圖是**正方形**（中間裁切），格線很密（〔app〕1dp）。
- [ ] **預設沒有時間篩選**：一進來就是完整時間軸，不會有預設條件藏掉較新的資料。
- [ ] 右上角日曆鈕 → 選一個月份 → 〔app〕日曆鈕變成**主色圖示＋主色圓底，圓底外圈有緩慢呼吸的光暈**（不另外出現狀態列）；再開選擇器按【清除】回到完整時間軸。
- [ ] 〔app〕**月份標題吸頂**：往下捲時年月一直貼在頂欄下方，捲到下個月由下個月的標題接手；吸在頂端時下緣有淡淡的陰影。
      **地點**在年月右邊、跟著吸頂；其他標籤在年月下方另一列，會跟著縮圖捲走。
- [ ] 月份標籤小膠囊**帶種類圖示與顏色**（地點＝定位、人物／動物／主題／其他各有圖示），點下去帶著該條件跳到查詢頁。
- [ ] ⏳ 月份標籤目前是**單行橫向捲動**（沿用原型現況）。要不要改為換行排列**尚未確認**，驗收時先不計成敗。
- [ ] 縮圖可以被 TalkBack 與實體鍵盤聚焦，選取後開啟 Lightbox。

## 三、Lightbox

- [ ] **背景是不透明的**，底層的月份標題與縮圖不會透出來。
- [ ] 上方顯示「第 N / 共 M 張」。
- [ ] 第一次開啟會出現一次性的「左右滑動看上一張／下一張」提示。
- [ ] 動作**分層**：一顆主要【播放這一段】＋兩顆圖示鈕（加入分類／分享），
      【編輯圖資】【刪除這張收藏】收在右上 `⋯` 裡 —— 刪除不該跟瀏覽動作並排。
- [ ] 頂列的關閉／更多與動作列的加入分類／分享圖示都清楚可見（Lightbox 底色固定是深色，圖示固定用白色，不隨主題色變）。

## 四、取圖

### 全流程
- [ ] **沒有底部導覽**，左上角是【✕】。三個步驟都一樣。
- [ ] 進度指示**有文字**：1. 貼網址 › 2. 挑畫面 › 3. 填資料。
- [ ] 動詞統一：【下一步】→【下一步】→【完成】。
- [ ] 第二／三步按【✕】→ 明確詢問「保留草稿並離開／捨棄草稿」，畫面上要說得出草稿還在不在。

### 第一步
- [ ] 歷史紀錄是**可點的清單列**（影片圖示＋標題＋日期＋張數），點了直接進第二步，
      不是只把網址填回輸入框。
- [ ] 亂打網址 → 錯誤訊息會說清楚該貼什麼格式。
- [ ] 〔app〕沒有網路時 → 就地顯示「取圖需要網路」，不換頁。
- [ ] 〔app〕年齡限制或需要登入的影片 → 「這支影片抓不到，可能是私人影片、已被刪除或需要登入」。

### 第二步
- [ ] **一進來就已經收斂過**：頂部狀態列顯示「已收斂成 50 張候選，隱藏了 98 張相似畫面」，
      而不是打開就是 148 格的候選牆。
- [ ] 按【顯示全部】→ 148 張全出現，狀態列變成【重新過濾】，可以來回切。
- [ ] 收斂強度沿用「帳號 › 取圖 › 過濾相似強度」（高／中／低）。
- [ ] **每格右上角有一顆 ▶**，點了跳到那一段；長按仍然有效，但不是唯一入口
      —— 鍵盤與輔助技術也要到得了。
- [ ] 工具列（全部選取／截圖／只看已選）**換行不截斷**，文字不會被切掉。
- [ ] 底部只有**一列**：「N 張候選 · 已選 k」＋【下一步（k 張）】，底下不再疊導覽列。
- [ ] 已收藏過的格子點下去會提示「這一格已經收藏過了」，不是靜靜地沒反應。
- [ ] 已選的格子是**主色框＋左上角打勾**，不用紅色；已收藏的格子整格變淡並標「已收藏」。
- [ ] 〔app〕【截圖】→ 播放器暫停、截下當下畫面，插進縮圖牆裡對應時間的位置，已勾選並帶「截圖」標記，播放器接著播。
- [ ] 〔app〕截不到時（黑畫面、廣告播放中）明確提示「這一格截不到」並提供【從相簿選】；廣告播放中【截圖】停用並說明原因。
- [ ] 〔app〕從相簿選的圖可以把時間 ±1 秒微調；截圖的時間不能調（圖與秒數是同一瞬間取的）。

### 第三步
- [ ] 底部收成**同一塊 dock**（抽屜＋按鈕），不是抽屜／按鈕列／導覽列三層把縮圖區壓到剩四成。
- [ ] **主按鈕會變**：沒動過欄位時是【完成】；動了任一欄位就變成【套用到 N 張】。
      流程終點（【完成】）永遠是最搶眼的那一顆。
- [ ] 動過欄位時，按鈕上方出現「將更新：地點、標籤　其他欄位維持各張原值」
      —— 這條規則要看得見，不能只存在於腦袋裡。
- [ ] 分兩輪套用仍然正確：先勾 8 張填一組 → 再勾另外幾張填另一組 → 前一輪不受影響。
- [ ] 時間欄位下方是中性說明「預設帶入 YouTube 的上傳日期，可以改成實際拍攝日」，
      不是欄位標題旁邊的橘色 ⚠ 警告。
- [ ] 在標籤欄位輸入文字後按鍵盤的完成鍵（Enter）= 加入該標籤（只有標籤欄位；地點與描述欄位的完成鍵
      不加任何東西）；任一欄位聚焦、鍵盤開著時，該欄位與底部按鈕都看得見，不會被鍵盤蓋住。
- [ ] 按【套用到 N 張】後，底部短暫顯示「已套用到 N 張」，縮圖右上角出現打勾；
      一動欄位或改勾選就回到「N 張 · M 已完成」。
- [ ] 【完成】→ 還有沒填的會提醒但不阻擋 → 回首頁、捲到該月份、toast「已新增 N 張」。

## 五、查詢

- [ ] **條件與結果在同一頁**：選完標籤按【查詢 N 個條件】→ 同頁換成結果，左上角出現返回鍵可以改條件，
      不會跳到另一個獨立頁面。結果頁按**系統返回鍵／手勢**也是回到條件頁（跟左上角返回鍵同一個去處），不是直接回首頁；
      從首頁月份標籤進來直接顯示結果時，要按兩次返回才會回首頁（第一次回條件頁、第二次回首頁）。
- [ ] 頂部是**底線分頁**「標籤與地點｜描述」，選中的分頁有主色底線；時間是滿版下拉欄位（標籤在上、值在下、右側向下箭頭），點了開月份選擇器。
- [ ] 每個標籤 chip **帶種類圖示、不顯示張數**（地點＝定位、人物／動物／主題／其他各有圖示與顏色）；沒選的是無框、四角圓角的主色淺底，選取後變成主色實心＋白字（明暗差大，不只靠色相；不打勾），TalkBack 唸「已選取」；按下效果只出現在看得到的膠囊上，觸控區仍至少 44dp 高。
- [ ] 按鈕停用時，下方會說**為什麼**：「先選一個以上的標籤或地點」，不是只把按鈕變淡。
- [ ] 按鈕文字會跟著選取數量變：【查詢 3 個條件】。
- [ ] 結果列顯示「N 張 · 全部日期」與條件小膠囊（純顯示，點了沒反應）；結果縮圖是**正方形**、格線很密，〔app〕樣式與每列張數同首頁；點一張開 Lightbox。
- [ ] 沒有符合的結果時，顯示置中圖示＋「沒有符合的收藏」。
- [ ] 從首頁的月份標籤點進來時，條件與時間會自動帶入並直接顯示結果。
- [ ] 動作列釘在導覽列上方，中間不會出現大段空白；開鍵盤（描述分頁）時動作列貼在鍵盤上方，同樣沒有多餘空白。
- [ ] 〔app〕描述分頁輸入文字後按鍵盤的搜尋鍵 = 按【查詢】。
- [ ] 〔app〕文字查詢的結果上方常駐「聽懂了：加勒比海・夜潛・大蝦　[修改]」。
- [ ] 〔app〕沒有設定 Gemini 金鑰（或離線）時文字查詢照樣可用，那一行結尾註明「（本機解析）」。
- [ ] 〔app〕兩個字的關鍵字（例如「大蝦」）也查得到。

## 六、分類

- [ ] 每張資料夾卡片有**內容預覽拼貼**（最多 4 張）；空的資料夾顯示「還沒有圖片」。
- [ ] 卡片的**張數是圖片區右下角的「N 張」膠囊**（含子資料夾），名稱列只有名稱與 `⋯`；空資料夾的「0 張」膠囊不與圖示或文字重疊。
- [ ] 清單上方狀態列左邊是「N 個分類」，右邊是目前排序（點了開排序選單，四個選項是單選，選中即套用）；搜尋沒有結果時顯示「沒有符合的分類」與【清除篩選】。
- [ ] 卡片右下有一顆看得見的 `⋯`（改名／刪除）；長按仍然有效，但不是唯一入口。
- [ ] 沒有任何資料夾時，空狀態帶一顆【新增資料夾】，不是只有一句灰字。
- [ ] 進入資料夾內容後，頂欄下方有**麵包屑**（分類 / 資料夾名稱）；縮圖是正方形，〔app〕樣式與每列張數同首頁；有子資料夾時以清單列顯示在縮圖上方。

## 七、詳細頁

- [ ] 播放器下方顯示**目前這一張的圖資**：描述、地點與標籤 chips、日期、影片秒數，
      以及一顆【編輯這張的圖資】—— 縮圖下方不該是大片空白。
- [ ] 圖資卡的標籤小膠囊**帶種類圖示與顏色**，純顯示、不可點。縮圖右上角的編輯鈕在亮的縮圖上仍看得見。
- [ ] 收藏縮圖右上角有**編輯鈕**；點縮圖＝跳播放，長按＝編輯（仍保留）。

## 八、帳號

- [ ] **漸層 hero ＋ 一張三格統計卡**。hero 顯示連結的 Google 帳號（名稱、Email、頭像字母），沒連結時顯示「尚未設定備份」（整塊可點進備份）；
      統計卡**跨在 hero 下緣**，三格各有圖示、格間有分隔線；選單是一組分組清單（六列、列間有分隔線）。
- [ ] **三格統計的數字正確**：收藏片段＝總張數、本月新增＝以事件日期落在本月的張數、
      來源影片＝去重後的影片數。三格都是可點的入口。
- [ ] **圖示對得上語意**：備份＝雲、縮圖＝圖片、取圖＝漏斗、查詢＝放大鏡、AI 分析＝星芒、標籤管理＝標籤。
      同一個圖示不會出現在兩個不同語意的地方。
- [ ] 【中斷連結】在最底、用破壞性樣式。
- [ ] **各細項頁用同一套設定頁元件**：取圖的過濾強度是三列單選（選中的有主色圓點）；AI 分析的往前／往後秒數是 −／＋ 步進器，到上下限時對應的鈕停用；
      查詢（Gemini 金鑰）【清除】是破壞性樣式；縮圖頁有儲存用量，回填中時有細進度條，【刪除這些收藏】是破壞性樣式。
- [ ] **標籤管理**：每個標籤一列，帶種類圖示（顏色對得上種類）；點一列開編輯，種類選擇是四顆可切換的小膠囊（選中的是主色實心），【刪除】（帶垃圾桶圖示）是破壞性樣式。
- [ ] 〔app〕備份頁（已連結）：【立即備份】【從 Drive 還原】並排，【中斷連結】在最底；備份失敗的訊息用警示色（不是紅色）。
      還原清單每列是日期＋張數·裝置·大小，確認框的【還原】是破壞性樣式（說明會取代本機收藏）。
- [ ] 各細項頁的說明文字是**這個設定會影響什麼**，不是操作教學句。
- [ ] **設定值真的存得住**：改過「過濾相似強度」與「AI 分析區間」之後關掉 app 再開，值應該還在。
      注意這兩項只存在這台手機，**換一台會回到預設值**，這是刻意的。
- [ ] 〔app〕Gemini 金鑰：可以輸入與清除；說明文字講清楚「只用於查詢解析、只存在這台手機」；換手機要重新輸入。

## 九、已知的取捨

- 「相似過濾」在原型裡是以**固定間隔**模擬（高＝每 5 張留 1、中＝每 3 張留 1、低＝每 2 張留 1），
  app 才是畫面指紋（dHash）；原型只是示意。
- 取圖第二步的縮圖牆來自 YouTube storyboard sprite。**這裡有兩種不同的降級，要分開驗**：
  - **sprite 網址簽章過期（圖回 403）** → 先重新取得影片資訊再試；仍然失敗才退回該影片的封面圖，縮圖牆照樣有東西可看。
  - **整支影片解不出 storyboard**（影片太短／直播中／剛上傳，或解析器失效）
    → 縮圖牆是空的，只開放【截圖】，**不當機**。
- 首頁與查詢結果讀的是存在手機上的單格縮圖，**不受 sprite 簽章過期影響**；上面那條降級只發生在取圖第二步的候選牆。
- Lightbox 全螢幕時圖會偏軟 —— 縮圖一律存 320×180，這是刻意的取捨。
- 詳細頁與分類頁在資料很少時仍會有下方留白 —— 這是資料量的結果，不是版面沒處理。
