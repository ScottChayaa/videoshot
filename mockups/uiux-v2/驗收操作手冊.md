# videoshot · 驗收操作手冊

> 對象：測試人員
> 環境：Android 手機直式（寬約 360–412dp）；另請至少開一次平板寬度（直向）
> 依據：[現行規格](../../docs/superpowers/specs/2026-09-10-videoshot-app-design.md)（含 2026-09-01 的 UI 決定，以及第六節最後的「UI 與原型的差異」）；
> [實作計畫](../../docs/superpowers/plans/2026-09-11-videoshot-android-實作計畫.md)的驗收條件引用本手冊的原文。
> **視覺的權威是 app 的共用元件**（開發測試版的元件總覽頁，列出每個元件的各種狀態）；
> `mockups/uiux-v2/` 的 HTML 原型是最初的視覺來源，現在只是歷史參考，兩者不一致時以 app 的元件為準。

**本手冊描述的是目標狀態。** 驗收對象是 **Android app**，所有條目都要驗。
開發測試版另有 `pnpm compare`（原型與實機並排截圖）可輔助對照；原型（`pnpm mock`，開 <http://localhost:8231/uiux-v2/login.html>，
原型保留登入頁作為入口，app 沒有登入）不再是驗收對象。標 **〔app〕** 的條目是只有 app 才有的行為。

標示 ⏳ 的是尚未確認的條目，驗收時先不計成敗。

## 零、先看整體（不必操作）

- [ ] **底部導覽有文字**：照片／取圖／相簿／帳號，四個項目都是圖示＋文字（〔app〕階段 17 拿掉「查詢」）。
- [ ] **底部導覽的「取圖」格與帳號格**〔app〕：「取圖」格是主色實心方塊（選中與否都是）；帳號格在連結 Google 之後，圖示換成頭像字母（顯示名稱的第一個字）。
- [ ] **紅色只用在破壞性動作**：只有「刪除」「中斷連結」這類動作是紅的，主要動作一律是主色。
- [ ] **間距與字級有尺標**：間距只用 4/8/12/16/24/32，字級只有 6 階。
- [ ] **不跟系統的深色模式走**：app 沒有深色模式，打開就是設定好的色系。把手機切成深色再開 app，畫面與系統列圖示都跟淺色時一樣。
- [ ] **輔助操作**：開 TalkBack 走一遍首頁，每個可點的東西都唸得出名稱；接上實體鍵盤時，用 Tab 走得到每個可點的東西、看得到焦點框。
- [ ] **平板寬度**：600dp 以上會加欄（平板也鎖直立，用直向驗；Android 16 以上的平板系統會強制跟著轉，橫向時取圖第二步的播放器最多占畫面高度 40%）。（桌機版面不做）
- [ ] 〔app〕**鎖定直立**：手機轉成橫的，照片、相簿、帳號、取圖都不跟著轉。只有橫的影片全螢幕時才轉橫向（見第四章第二步的播放器、第七章原片播放）。

## 一、備份與還原〔app〕

> app 不需要登入。Google 帳號只用來把圖庫備份到使用者自己的 Google Drive。

- [ ] **不連結 Google 也能完整使用**：帳號頁顯示「尚未設定備份」與【連結 Google 帳號以啟用備份】。
- [ ] **授權範圍很小**：連結時的 Google 授權畫面只要求「app 自己的設定資料」，不該出現「查看／管理你所有的 Drive 檔案」。
- [ ] **手動備份**：帳號頁【立即備份】→ 完成後顯示「上次備份：剛剛」與檔案大小。
- [ ] **自動備份**：有新增或修改、連著 Wi-Fi 的情況下，隔天不必開 app，帳號頁的「上次備份」也會更新。
- [ ] **全新安裝的第一個畫面**：可選【從 Google Drive 還原】或【全新開始】。還原清單顯示最近 3 份備份的日期、張數、來源裝置。
- [ ] **還原後立刻能用**：圖資、標籤、地點、資料夾、截圖都在；storyboard 縮圖先顯示該影片的封面，之後逐漸換成正確的畫面。
- [ ] **覆蓋前說清楚**：從帳號頁還原時，確認框說得出「本機的 N 張收藏會被取代，未完成的取圖草稿也會捨棄」。
- [ ] **還原失敗不會壞掉**：還原途中關掉網路 → 原本的資料完好，不會變成半套。
- [ ] **回填看得到進度**：帳號頁顯示「縮圖回填中 320 / 1,200」；只在 Wi-Fi 下進行，進度卡片上有【用行動網路繼續】。
- [ ] **抓不回來的縮圖**：已刪除或轉私人的影片，它的縮圖顯示中性的預留圖並標影片秒數，不是破圖；
      帳號頁顯示「無法取回 N 張」，有【稍後重試】與【刪除這些收藏】。
- [ ] 〔app〕**縮圖還在載入**：格子是灰色骨架塊，不會先閃一下圖示或秒數再換成圖（照片頁、相簿、Lightbox、取圖第二與第三步都一樣）。
- [ ] **中斷連結**：【中斷連結】在帳號頁最底、用破壞性樣式。

## 二、首頁（照片）

- [ ] 〔app〕底部導覽第一格與頂欄標題都叫「照片」（導覽列圖示是圖片）。
- [ ] 〔app〕**長按一張進入多選**：頂欄變成【✕】＋「已選 N 張」（篩選與日曆鈕收起來）；已選的格子有主色框與左上打勾，其他格子左上有空心圈；多選中點一下是切換選取、不開 Lightbox；取消最後一張、按【✕】或系統返回鍵都離開多選。
- [ ] 〔app〕多選中**底部導覽藏起來**，換成一列動作列（高度同底部導覽），兩顆按鈕都是圖示＋下方文字：【刪除】（垃圾桶，先跳確認框「刪除 N 張照片？」）、【加入相簿】（開「把 N 張加入相簿」抽屜，勾一個相簿＝選了的全部加進去）。

- [ ] **每個月份欄數都一樣**，不隨當月張數改變；手機預設每列 4 張，〔app〕帳號 › 縮圖可改成 2／3／4 張，重開 app 仍記得。
- [ ] 〔app〕縮圖**直角**、左右**貼齊螢幕邊緣**；月份標題與標籤列左右仍有留白。
- [ ] **卡片上只有縮圖，沒有描述文字**；縮圖是**正方形**（中間裁切），格線很密（〔app〕1dp）。
- [ ] **預設沒有時間篩選**：一進來就是完整時間軸，不會有預設條件藏掉較新的資料。
- [ ] 〔app〕**月份選單只列有圖的月份，不帶每個月的張數**；篩選中只列「選取項目在那個月有圖」的月份，一個都沒有時顯示「沒有符合篩選的月份」。
- [ ] 右上角日曆鈕 → 選一個月份 → 〔app〕日曆鈕變成**主色圖示＋右上角主色小圓點**（不另外出現狀態列）；再開選擇器按【清除】回到完整時間軸。
- [ ] 〔app〕**月份標題吸頂**：往下捲時年月一直貼在頂欄下方，捲到下個月由下個月的標題接手；吸在頂端時下緣有淡淡的陰影。
      **地點**在年月右邊、跟著吸頂；其他標籤在年月下方另一列，會跟著縮圖捲走。
- [ ] 月份標籤小膠囊**帶種類圖示與顏色**（地點＝定位、標籤＝`#`；〔app〕標籤不分種類），〔app〕點下去直接在首頁套用「只篩這一個」（時間範圍不變，不跳頁）。
- [ ] 〔app〕**篩選鈕**：頂欄右上角、日曆鈕的左邊（三條由長到短的橫線），TalkBack 唸「依地點與標籤篩選」；有篩選時變成主色圖示＋右上角主色數字徽章（套用幾個條件，超過 9 寫 9+），並唸出「已套用 N 個篩選條件」。
- [ ] 〔app〕**篩選抽屜**：標題「篩選」、右上角文字樣式的【清除】（有勾選時主色＋底線、可以按，沒勾選時灰字）；「地點」與「標籤」兩區，各自標題右邊是〔搜尋〕圖示鈕（點了展開成搜尋框、鍵盤跳出；有字時右邊有【✕】一鍵清除；框空著時收起鍵盤就收回成圖示），下面是可多選的小膠囊（不顯示張數）；底部有主色【套用】，鍵盤開著時【套用】貼在鍵盤上方、看得到。
- [ ] 〔app〕**按【套用】才生效**：勾幾個項目後關掉抽屜（沒按【套用】），首頁沒變，再開抽屜剛才的勾選不見（草稿作廢）；【清除】也要再按【套用】才清掉首頁的篩選。
- [ ] 〔app〕**搜尋框打字即時過濾**，名稱與別名都比對得到（打舊名字也找得到合併過去的地點）；沒有符合時顯示「找不到符合的地點」（標籤同理）。
- [ ] 〔app〕**候選清單**：只列目前時間範圍內有圖的項目，依全部時間的張數排序；已勾選但不在範圍內的項目照樣列在最前面。每區最多列 100 個、其餘用搜尋找（下面有「還有 N 個沒列出」）；已勾選但排在 100 名之後的項目一定看得到。小膠囊每頁最多 4 列，多的左右滑，下面點點顯示第幾頁。
- [ ] 〔app〕**篩選抽屜與月份選擇器的標題列一樣高**，下面都有一條細線。
- [ ] 〔app〕**多選是任一個符合**：勾兩個地點，首頁顯示符合其中任何一個的圖。
- [ ] 〔app〕**篩選中的首頁**：只顯示符合的圖，月份分組與吸頂標題照舊；月份旁的地點與標籤小膠囊隱藏、不顯示「N 張」；換了篩選捲回頂端；點圖開 Lightbox，上下滑只在篩選後的圖之間。
- [ ] 〔app〕**0 張**時顯示「沒有符合篩選的照片」＋【清除篩選】，按了直接回到全部的圖。
- [ ] 〔app〕**篩選中改了圖、刪了圖、取了圖**：在 Lightbox 編輯一張圖的圖資後，Lightbox 不會自己關掉或跳到別張，首頁捲動位置不變；改完不再符合篩選的那張從清單拿掉，不會留在畫面上。刪單張就地拿掉那一張。完成取圖後首頁回到沒有篩選的狀態並捲到新圖的月份。在帳號頁的地點管理或標籤管理按【儲存】、合併、刪除之後，首頁回到沒有篩選的狀態。
- [ ] 〔app〕**篩選抽屜的候選還在讀**：顯示骨架屏（灰色色塊，一道亮光由左往右掃過），不會說「這段時間沒有地點」；讀不到時抽屜裡有【重試】，首頁不跳錯誤列。
- [ ] 〔app〕**篩選鈕的抽屜跟日曆鈕一樣快跳出來**：滑出來的途中是骨架屏、不會卡一下，停穩後才換成小膠囊。
- [ ] ⏳ 月份標籤目前是**單行橫向捲動**（沿用原型現況）。要不要改為換行排列**尚未確認**，驗收時先不計成敗。
- [ ] 縮圖可以被 TalkBack 與實體鍵盤聚焦，選取後開啟 Lightbox。

## 三、Lightbox

- [ ] **背景是不透明的**，底層的月份標題與縮圖不會透出來。
- [ ] 〔app〕頂列：左上角返回箭頭、旁邊是日期（不顯示影片秒數）、日期右邊是地點小膠囊（沒有地點就不畫）、最右是 ⋯；不顯示第幾張。
- [ ] 〔app〕頂列下方一列標籤小膠囊，只有一列、放不下可以左右滑，不會換成多列；沒有標籤時這一列仍留著，換張時大圖不上下跳。
- [ ] 〔app〕描述在底部動作列上方、固定兩行；橫的與直的照片描述位置一樣。
- [ ] 〔app〕直的照片（Shorts）完整直著顯示、不被裁成橫的。
- [ ] 〔app〕不出現「上下滑動看上一張／下一張」這類滑動提示。
- [ ] 動作**分層**：一顆主要【原片播放】＋兩顆圖示鈕（加入相簿／分享），
      【詳細資料】【刪除】收在右上 `⋯` 裡 —— 刪除不該跟瀏覽動作並排。
- [ ] 頂列的返回／更多與動作列的加入相簿／分享圖示都清楚可見（Lightbox 底色固定是深色，圖示固定用白色，不隨主題色變）。
- [ ] 〔app〕**自動播放片段**：停在一張圖 1 秒後，大圖淡入換成那個時間點的影片，有聲音，循環播 3 秒；
      網路慢時先維持縮圖，影片真的播出畫面才換上去，不出現黑畫面或轉圈；影片抓不到時一直是縮圖、不跳錯誤。
- [ ] 〔app〕點一下播放中的影片，叫出跟取圖第二步同一套控制層（畫面調暗、中央播放／暫停、右下【聲音】【全螢幕】），影片沒有暫停；
      **沒有**左下時間與下緣進度條，左右拖不會跳播；3 秒沒動作自己收起，點中央以外的地方也收起；中央鈕點了暫停／繼續。
- [ ] 〔app〕點兩下影片暫停、再點兩下繼續循環，中央閃一下圖示；手指一開始上下拖，影片立刻暫停換回縮圖、按鈕收起，停到新的一張重新倒數。
- [ ] 〔app〕【聲音】按一下馬上靜音、再按一下馬上有聲音；靜音後換張、關掉 Lightbox 再開、重開 app 都還是靜音。
- [ ] 〔app〕【全螢幕】：只剩影片（系統列也藏起來），照樣循環 3 秒、上下滑換張；橫的影片按下去轉橫向、直的維持直向，之後換張不再轉向；
      再按一次按鈕或系統返回鍵離開全螢幕（返回鍵不會關掉 Lightbox），離開前後影片不重載。
- [ ] 〔app〕⋯ 選單、刪除確認框、加入相簿與詳細資料抽屜打開時影片暫停，關掉後繼續；切到背景沒有聲音；
      按【原片播放】後只有原片播放的播放器在出聲。
- [ ] 〔app〕直的影片（Shorts）的片段直著撐滿高；影片外的留白是 Lightbox 底色，不是純黑塊。

## 四、取圖

### 全流程
- [ ] **沒有底部導覽**，左上角是返回鍵、右上角是【✕】，沒有步驟條。三個步驟都一樣。
- [ ] 〔app〕頂欄返回鍵與系統返回鍵行為一樣：第二、三步回上一步且選擇還在，第一步離開取圖。
- [ ] 動詞統一：【下一步】→【下一步】→【完成】。
- [ ] 〔app〕在第二步勾幾張後一路按返回離開，再按【取圖】**不詢問**、直接回到第二步，剛才的勾選都在（app 重開過也一樣）。
- [ ] 〔app〕任一步按右上角【✕】→ 直接離開取圖；再按【取圖】從第一步開始，剛才的勾選與截圖都不在了。

### 第一步
- [ ] 歷史紀錄是**可點的清單列**（影片圖示＋標題＋日期＋張數），點了直接進第二步，
      不是只把網址填回輸入框。
- [ ] 亂打網址 → 錯誤訊息會說清楚該貼什麼格式。
- [ ] 〔app〕沒有網路時 → 就地顯示「取圖需要網路」，不換頁。
- [ ] 〔app〕年齡限制或需要登入的影片 → 「這支影片抓不到，可能是私人影片、已被刪除或需要登入」。

### 第二步
- [ ] **一進來就已經收斂過**：頂部狀態列顯示「50 張照片，隱藏 98 張相似畫面」，
      而不是打開就是 148 格的候選牆。
- [ ] 按【顯示全部】→ 148 張全出現，狀態列寫「全部 148 張」（有手動截圖的話一起算），按鈕變成【重新過濾】，可以來回切。
- [ ] 收斂強度沿用「帳號 › 取圖 › 過濾相似強度」（高／中／低）。
- [ ] 〔app〕縮圖牆同照片頁：每列 4 張正方形、格線很細；點一下只打勾（不畫框）。
- [ ] 〔app〕格子上沒有 ▶；**長按**跳到那一段開始播（TalkBack 動作選單有「跳到這一段」）。
- [ ] 〔app〕播放中主色外框跟著播放位置走到對應的格子；播放器下方有細進度條跟著前進。
- [ ] 〔app〕**播放器**（原片播放同一套，但沒有全螢幕鈕）：畫面上看不到 YouTube 的任何按鈕或文字。點一下叫出控制層（中央播放／暫停、下緣變粗的進度條帶目前時間與總長、右下【聲音】與全螢幕），3 秒沒動作自己收起（暫停中不收）；再點一下收起。
- [ ] 〔app〕【聲音】按一下馬上靜音、再按一下馬上有聲音；第二步與原片播放共用，重開 app 還記得；跟 Lightbox 片段的聲音設定互不影響。
- [ ] 〔app〕**點兩下**播放／暫停，控制層開著或收著都一樣。
- [ ] 〔app〕接上實體鍵盤：Tab 走得到影片（看得到焦點框），Enter／空白鍵播放暫停、←／→ 前後 10 秒、F 全螢幕。

## 九、已知的取捨

- 「相似過濾」在原型裡是以**固定間隔**模擬（高＝每 5 張留 1、中＝每 3 張留 1、低＝每 2 張留 1），
  app 才是畫面指紋（dHash）；原型只是示意。
- 取圖第二步的縮圖牆來自 YouTube storyboard sprite。**這裡有兩種不同的降級，要分開驗**：
  - **sprite 網址簽章過期（圖回 403）** → 先重新取得影片資訊再試；仍然失敗才退回該影片的封面圖，縮圖牆照樣有東西可看。
  - **整支影片解不出 storyboard**（影片太短／直播中／剛上傳，或解析器失效）
    → 縮圖牆是空的，只開放【截圖】，**不當機**。
- 首頁（含篩選中）與資料夾讀的是存在手機上的單格縮圖，**不受 sprite 簽章過期影響**；上面那條降級只發生在取圖第二步的候選牆。
- Lightbox 全螢幕時圖會偏軟 —— 縮圖一律存 320×180，這是刻意的取捨。
- 詳細頁與分類頁在資料很少時仍會有下方留白 —— 這是資料量的結果，不是版面沒處理。
