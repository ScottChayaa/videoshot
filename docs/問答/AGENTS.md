# 問答的格式規則

`docs/問答/` 收錄開發時常查的問題。規則先求簡單，之後再慢慢補。

## 結構

- `README.md` 是**目錄**：依分類列出問題連結，不寫答案
- **一題一個檔案**，不要把多題塞進同一個檔案
- 檔名用問題的簡短中文說法（例：`首頁的圖存在哪裡.md`），不加編號或日期

## 每題的檔案

- 第一行：`# 問題原文？`
- 第二段：`[← 回目錄](README.md)`
- 答案：**精簡、條列**，有指令就放 `bash` 程式碼區塊
- 結尾（有的話）：`相關：` 加上相關題目的連結

## 內容

- 只寫不會過時的事實與做法；手機當下的檔案數、某天的測試數這類快照不寫
- 跟規格衝突時以規格為準；規格改了，對應的問答也要跟著改

## 新增一題

1. 在 `docs/問答/` 加一個檔案
2. 把連結加到 `README.md` 對應的分類；沒有合適的分類就新開一個
