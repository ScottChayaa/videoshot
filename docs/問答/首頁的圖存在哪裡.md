# 首頁的圖存在哪裡？

[← 回目錄](README.md)

依序找，用第一個找得到的：

1. **一般的圖**（從縮圖牆挑的）
   - 檔案：`files/thumbs/{影片ID}/L{層級}/{格子編號}.webp`
   - 不備份，可從 YouTube 重抓
2. **手動截圖的圖**（【截圖】或相簿選圖）
   - 存在 `library.db` 的 `shot_image` 表（WebP，約 6 KB／張）
   - 會備份，重抓不回來
3. **一般的圖，檔案還沒抓到**（例如剛還原、回填還在跑）
   - 先顯示影片封面 `i.ytimg.com/vi/{影片ID}/hqdefault.jpg`
   - 快取在 `cache/covers/`，清掉沒關係
4. **確定抓不回來**（影片下架），或手動圖遺失
   - 顯示中性預留圖，不存檔

補充：

- DB 不存檔案路徑，只存「影片、層級、格子編號」，路徑由這三個值組出來
- `thumbs/` 放在 `files/` 不放 `cache/`，免得「清除快取」把圖庫縮圖清掉
- 備份到 Drive 的只有 `library.db`；換手機還原後，一般的圖靠回填重抓
- 程式：`android/app/src/main/java/com/xenyaa/videoshot/thumbs/FileThumbs.kt`、`ThumbKey.kt`
