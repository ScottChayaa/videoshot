# 儀器測試（androidTest）怎麼跑才算數？

[← 回目錄](README.md)

- **不要信 Gradle 的 `BUILD SUCCESSFUL`**：安裝被擋時它照樣回報成功、exit code 0，但一個測試都沒跑
  - 常見原因：MIUI 的「透過 USB 安裝」會自己關掉
  - 新版 AGP 只產 `.pb` 不產 XML，用 XML 數測試數會誤判成 0
- 自己裝、自己跑，最後一行印出 `OK (N tests)` 才算數：

  ```bash
  adb install -r -t app/build/outputs/apk/debug/app-debug.apk
  adb install -r -t app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
  adb shell am instrument -w -e package com.xenyaa.videoshot \
    com.xenyaa.videoshot.test/androidx.test.runner.AndroidJUnitRunner
  ```

  （在 `android/` 底下跑；兩個 APK 先用 `./gradlew assembleDebug assembleDebugAndroidTest` 建好）
- **被 `assumeTrue` 略過的測試照樣算在 `OK (N tests)` 裡**：沒權限、沒資料而略過時最後一行還是 `OK`
  - 加 `-r`（原始輸出）再跑，每個案例結束會有一個 `INSTRUMENTATION_STATUS_CODE`：`0` 是通過、`-4` 是被略過
  - 只有沒出現 `-4` 的案例才算真的跑過：

    ```bash
    adb shell am instrument -w -r -e class 完整類別名 \
      com.xenyaa.videoshot.test/androidx.test.runner.AndroidJUnitRunner | grep -E 'STATUS_CODE|^OK'
    ```
- 只跑某幾個類別：把 `-e package …` 換成 `-e class 完整類別名,完整類別名`
- **`./gradlew :app:connectedDebugAndroidTest` 跑完會把 app 解除安裝**（AGP 的 `uninstall-after-tests=true`），**手機上的 `library.db` 會一起消失**
  - 用上面 `am instrument` 的跑法不會解除安裝
  - 要用種子資料驗收時，順序是先跑儀器測試、再塞資料
- 量測類的測試（例如 `-e benchMerge true`）會改動量測庫，跑完要重造
