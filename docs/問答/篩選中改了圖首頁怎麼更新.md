# 首頁篩選中，改了或刪了圖，首頁怎麼更新？

[← 回目錄](README.md)

篩選中（首頁頂欄的篩選鈕呈作用中），依動作不同：

| 動作 | 首頁怎麼更新 | 為什麼 |
|---|---|---|
| 編輯一張圖的圖資（詳情頁【編輯這張的圖資】） | **整個重新讀取**（從第一頁重新載入） | 改了地點或標籤後，這張圖可能已經不符合篩選；首頁手上只有地點、沒有標籤，判斷不了，所以重讀，不符合的就不會留在畫面上 |
| 批次編輯圖資 | 整個重新讀取 | 一次改很多張，同上 |
| 刪除一張圖（Lightbox ⋯） | 從清單拿掉那一張，不重讀 | 刪掉的一定不在了，直接拿掉就好 |
| 刪除整支收藏 | 整個重新讀取 | 同一支影片的圖可能散在很多個月 |
| 在帳號頁把地點或標籤改名、合併、刪除 | **篩選清空**，回到全部的圖 | 篩選記的是名字，舊名字可能已經不存在，留著會查不到東西又看不出原因 |

沒有篩選時，編輯一張圖只更新那一張，不重讀，捲動位置不變。
