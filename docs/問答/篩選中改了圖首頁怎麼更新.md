# 首頁篩選中，改了或刪了圖，首頁怎麼更新？

[← 回目錄](README.md)

篩選中（首頁頂欄的篩選鈕呈作用中），依動作不同：

| 動作 | 首頁怎麼更新 | 為什麼 |
|---|---|---|
| 編輯一張圖的圖資（Lightbox ⋯【編輯圖資】、詳情頁【編輯這張的圖資】） | **就地更新那一張**；改完已經不符合篩選（地點與標籤都對不上了）就從清單拿掉。不重讀，捲動位置不變 | 重讀會先把清單清空：開著的 Lightbox 看到空清單會自己關掉，沒關也會被換成前 50 張而跳到別張。地點直接比對名稱，標籤另外查這一張的標籤 |
| 批次編輯圖資 | 整個重新讀取 | 一次改很多張，逐張判斷不划算 |
| 刪除一張圖（Lightbox ⋯） | 從清單拿掉那一張，不重讀 | 刪掉的一定不在了，直接拿掉就好；Lightbox 停在下一張 |
| 刪除整支收藏 | 整個重新讀取 | 同一支影片的圖可能散在很多個月 |
| 完成取圖 | **篩選清空**，回到全部的圖，捲到新圖的月份 | 新圖多半不符合篩選，留著篩選就看不到剛取的圖 |
| 在帳號頁的地點管理或標籤管理按【儲存】（只改種類或別名也算）、合併、刪除 | **篩選清空**，回到全部的圖 | 篩選記的是名字，舊名字可能已經不存在，留著會查不到東西又看不出原因 |

沒有篩選時，編輯一張圖只更新那一張，不重讀，捲動位置不變。
