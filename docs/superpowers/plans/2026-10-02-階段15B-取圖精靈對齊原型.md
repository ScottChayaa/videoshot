# 階段 15B：取圖精靈對齊原型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 取圖精靈三個步驟（外殼、第一步、第二步、第三步）的外觀換成原型 `capture.html` 的樣子，改用階段 15A 的共用元件；同時修掉第二、三步「已選用紅框」違反手冊 §零的問題、第三步鍵盤蓋住欄位與 Enter 不能加標籤的操作缺陷，並在套用後補一行「已套用到 N 張」提示。

**Architecture:** 只動畫面層（`wizard/*Screen.kt`）與兩個小狀態欄位；規則仍在 `Step2Store`／`Step3Store`／`WizardViewModel`，不改流程。精靈外殼從 Material `Scaffold` 換成「`VsTopBar`＋`VsStepIndicator`＋內容」的 `Column`，各步的底部一律用 `VsActionDock`（它自己處理系統導覽列與鍵盤 inset）。15A 最終審查指名「15B 採用前要修」的三項元件細節在 Task 1 先修。

**Tech Stack:** Kotlin、Jetpack Compose、Robolectric（`:app:testDebugUnitTest`）、`pnpm compare`（對照截圖）。

**Spec:** [`docs/superpowers/specs/2026-10-01-UI對齊原型-design.md`](../specs/2026-10-01-UI對齊原型-design.md)（以下稱「設計文件」，第五節＝計畫 B）；視覺來源 `mockups/uiux-v2/capture.html` 與 `styles.css`「取圖精靈」段落；行為依據規格第五節與驗收手冊 §四。

## Global Constraints

- 外觀照原型、行為照驗收手冊與規格（設計文件決定 1）。**不改任何流程規則**：勾選、收斂、截圖、草稿、套用語意（規格第五節「套用語意」表：沒動過的欄位不套用、`〈多個值〉`、勾 1 張＝單張編輯）全部維持。
- **紅色只用在破壞性動作**（手冊 §零）：已選狀態一律 `accent`；錯誤／提示類訊息用 `warn` 系列，**不用 `danger`**。
- 間距只用 4／8／12／16／24／32；字級只有 13／15／17／20／24／28；字重 Regular／Medium／Bold；圓角 8／12／全圓。
- 觸控目標最小 44dp（格子右上的 ▶ 例外：維持既有 40dp 並保留 `Step2GridScreen.kt` 註解裡的理由——整格點擊不可被它蓋住）；每個可點的東西都有 `focusRing()` 與 TalkBack 名稱。
- 元件不寫死色碼（`Color.White`／半透明黑的「圖上疊字」除外，原型 `.tm`／`.peek` 也是固定白字＋scrim，改用 `AppTheme.colors.scrim`）。
- **既有測試不得刪除或弱化**。因為文字或結構改變而必須調整的測試，最小幅度修改並在測試裡用註解說明原因。
- commit message 用繁體中文，格式 `類型(範圍): 描述`，**不加 AI 生成標記**。
- 這台開發機 PATH 上沒有 java：`export JAVA_HOME=/snap/android-studio/current/jbr ANDROID_HOME=$HOME/Android/Sdk; export PATH=$PATH:$ANDROID_HOME/platform-tools`；Gradle 指令在 `android/` 下跑。

**Interfaces:**
- Produces:
  - `VsStepIndicator(steps: List<String>, current: Int, modifier: Modifier = Modifier, furthest: Int = current, onStepClick: ((Int) -> Unit)? = null)`——`i != current && i <= furthest` 的步驟可點；`i < current` 的顯示「‹ 」前綴（只是視覺，TalkBack 唸「回到 N. 名稱」）；`current < i <= furthest` 的步驟可點、無前綴、文字色 `textDim`，TalkBack 唸「前往 N. 名稱」
  - `VsToolbarPill(...)` 簽章不變；`selected` 寫進語意（`Modifier.semantics { selected = … }`）
  - `enum class TextFieldSize { Regular, Dense }`
  - `@Composable fun VsTextField(value: String, onValueChange: (String) -> Unit, modifier: Modifier = Modifier, label: String? = null, labelAccent: Boolean = false, placeholder: String? = null, supporting: String? = null, mixedPlaceholder: Boolean = false, isError: Boolean = false, enabled: Boolean = true, size: TextFieldSize = TextFieldSize.Regular, keyboardOptions: KeyboardOptions = KeyboardOptions.Default, keyboardActions: KeyboardActions = KeyboardActions.Default, semanticLabel: String? = label)`
  - `VsIcons.Eye`

**VsTextField 規格**（原型 `.wz-field`、`.meta-drawer .field`）：
- 標籤在欄位**上方**（不是浮動標籤）：15 Medium `textDim`，與欄位間距 8。`labelAccent = true` 時標籤變 `accent`，且標籤前多一顆 6dp `accent` 圓點；為了不讓文字位移，**圓點位置永遠保留**（不亮時透明）——原型 `.field.will-write`。圓點亮起時帶 `contentDescription = "將寫入"`、不亮時沒有語意，讓輔助技術也分得出哪些欄位會被寫入（不只靠顏色）。
- Regular：底 `surface`、1dp `borderStrong` 框、圓角 8、內距 12、字 17。Dense：底 `surface2`、1dp `border` 框、內距上下 8 左右 12、字 15。
- 聚焦：框變 `accent`，外圈多一圈 3dp `accentWeak`（原型 `box-shadow: 0 0 0 3px var(--accent-weak)`）。
- `placeholder`：`textFaint`；`mixedPlaceholder = true` 時佔位字樣改用斜體 `textDim`（原型 `.mix::placeholder`，用來顯示〈多個值〉）。
- `supporting`：欄位下方 13 `textDim`，間距 4。`isError = true` 時框變 `warn`（不是紅色）。
- 實作用 `BasicTextField` ＋ `decorationBox`，不用 Material `OutlinedTextField`（它的浮動標籤與原型不符）。語意：`semanticLabel` 寫成整個欄位的 `contentDescription`（既有精靈測試用「時間」「地點」「描述」「新增標籤」定位欄位）。

- [ ] **Step 1：對照腳本加取圖第二、三步**

`ui-compare.mjs` 的實機步驟加 `{ tapTextPrefix: '…' }`：`text` 或 `content-desc` **以該字串開頭**的第一個節點（處理方式同 `tapDescPrefix`）。

`ui-compare.screens.mjs` 加：

```js
  {
    name: '取圖第二步',
    mockup: { path: 'capture.html', steps: [{ click: '.wz-hist .hrow' }] },
    device: { steps: [{ tapText: '取圖' }, { wait: 800 }, { tapTextPrefix: '80後老登勇闖加勒比海無人島' }, { wait: 6000 }] },
  },
  {
    name: '取圖第三步',
    mockup: { path: 'capture.html', steps: [{ click: '.wz-hist .hrow' }, { click: '.wz-cell:not(.locked)' }, { click: '.wz-foot .btn' }] },
    device: { steps: [{ tapText: '取圖' }, { wait: 800 }, { tapTextPrefix: '80後老登勇闖加勒比海無人島' }, { wait: 6000 },
                      { tapDescPrefix: '第 2 格' }, { tapTextPrefix: '下一步' }, { wait: 1500 }] },
  },
```

> - 原型的選擇器以 `capture.html` 實際的 class 為準（`grep -n "hrow\|wz-cell\|wz-foot" mockups/uiux-v2/capture.html`）；畫面切換需要時間的話，在 `click` 之後補 `{ wait: 毫秒 }`（原型端也支援這個步驟）。實機第二步要連網抓 watch page，6 秒不夠就加長。
> - 每個畫面開始前腳本都會 force-stop app（既有行為），不必另外退出精靈。但精靈會留草稿，下次點同一支影片可能跳出「上次做到…要繼續嗎？」：給 `tapText` 加 `optional: true` 選項（找不到節點時略過、不算失敗），並在實機第二、三步點完取圖紀錄後加 `{ wait: 800 }, { tapText: '重新開始', optional: true }`。
