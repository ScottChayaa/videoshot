# 階段 23：YouTube 權限送 Google 審核 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目標：** 讓 `youtube.upload` 通過 Google 的 OAuth 審核（第一次授權不再出現「Google 尚未驗證這個應用程式」、不再有 100 位使用者上限）。送審前先把 app 補到符合 YouTube API 開發者政策，再定稿範圍說明、錄示範影片、在 Cloud Console 送出。

**架構：** 程式只改兩件事：導出時可以選公開狀態（Task 1），app 裡看得到 YouTube 服務條款與隱私權政策（Task 2）。其餘是文件與 Console 操作：範圍說明定稿（Task 3）、示範影片腳本與錄製（Task 4，scott 錄）、送審與等回覆（Task 5，scott 操作）。

**技術：** Kotlin、Compose、Room（`cache.db` 5 → 6）、OkHttp（`videos.insert` 的 `status.privacyStatus`）、Robolectric、MockWebServer；網站在 `site/`（Cloudflare Workers，`wrangler deploy`）。

**規格：** [`../specs/2026-09-10-videoshot-app-design.md`](../specs/2026-09-10-videoshot-app-design.md) 第十節（Google Cloud 專案、品牌）、第十九節「導出」「背景任務」「完成後」「Google 授權與 YouTube 權限」「資料」；路線圖[階段 23](2026-09-11-videoshot-android-實作計畫.md)。

不在這次審核範圍、但要知道的：

- **專案每天 100 次上傳、所有使用者共用**（規格第十九節「每日上限」）。要提高額度得另外通過 **YouTube API 合規稽核**，跟這次的 OAuth 審核是兩回事；稽核也會看 Task 1、Task 2 這些政策條款。使用者多起來再排。
- **Play Console 的前景服務申報**（`dataSync`／`mediaProcessing`）要等上架才做（已知缺口「還沒做的功能」）；OAuth 審核不需要先上架。
- 審核員若要求實際操作 app，可能要提供 APK 或測試說明；到時再依對方要求準備。

## scott 的決定（2026-10-31）

1. **導出時加公開狀態的選項，預設非公開**：非公開（預設）／公開／私人三選一。
2. **app 裡兩處都加**：導出抽屜加「上傳即表示同意 YouTube 服務條款」（可點）；帳號頁加「隱私權政策」連結。

## 全域限制

- 路徑簡寫：`app/…` ＝ `android/app/src/main/java/com/xenyaa/videoshot/…`，`test/…` ＝ `android/app/src/test/java/com/xenyaa/videoshot/…`。
- `edit_task` 只走 `CacheRepo`；YouTube Data API 只在 `publish/`（規格邊界 7）。
- 公開狀態的值照 YouTube API：`unlisted`／`public`／`private`；畫面上叫「非公開」「公開」「私人」，順序就是這個（預設在第一個）。
- 網址：YouTube 服務條款 `https://www.youtube.com/t/terms`、隱私權政策 `https://videoshot.scottchayaa.com/privacy`（跟同意畫面上的同一個）。
- 這個計畫自己定的值（Claude 的決定，可推翻）：
  - **選私人時不等縮圖、不接回取圖** ⏳：私人影片不登入抓不到 watch page 與 storyboard，取圖精靈接不上。上傳完直接算已完成；已完成畫面寫「已上傳到 YouTube（私人）」，小字「私人影片無法在 app 裡取圖」，刪除問句照樣問，按鈕是【刪除原檔】【保留】（按了移除任務、回剪輯頁，不進取圖）。選私人時抽屜裡多一行小字「私人影片無法在 app 裡取圖」。
  - 公開狀態用單選列（`VsRadioRow` 這類既有元件），放在標題欄下面；原本的「以「非公開」上傳到你的 YouTube」那行拿掉，換成「上傳即表示同意 YouTube 服務條款」。
  - 剪輯頁空狀態的「上傳到你的 YouTube（非公開）後，就能用取圖精靈挑畫面」改成「上傳到你的 YouTube 後，就能用取圖精靈挑畫面」；已完成畫面的「已上傳到 YouTube（非公開）」改成照任務的公開狀態。

## Review Focus

### Task 3：範圍說明定稿

- [ ] 把下面這段寫回規格第十九節「Google 授權與 YouTube 權限」，取代草稿（約 870 字元）：

> videoshot is an Android app that lets users combine photos and videos stored on their own phone into a short video. When the user taps Start in the Export panel, after entering a title and choosing a visibility (Unlisted by default, Public or Private), the app uses youtube.upload to upload that one video to the user's own YouTube channel. Once YouTube has processed an Unlisted or Public video, the user can browse its frames in the app and save still frames to a personal photo library on the phone. The app only uploads the video the user just created and explicitly chose to export. It never reads, modifies or deletes the user's other videos or channel data, and no Google user data is sent to any server we operate. youtube.upload is the narrowest scope that allows videos.insert; youtube and youtube.force-ssl would grant read and write access we do not need.
