# Lightbox 自動播放片段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lightbox 停在一張圖 2 秒後，大圖淡入換成那個時間點的影片，有聲音、循環播 3 秒；點一下暫停／繼續，開始左右拖就停。

**Architecture:** 整個 Lightbox 只有一個 WebView（`ClipPlayerSurface`），放在 `HorizontalPager` 的下面一層；影片要出來時把目前那一頁的縮圖淡成透明。
流程（倒數、靜音預載、開始循環、暫停、被蓋住、換頁）集中在不碰 Compose 的 `LightboxClipController`，透過 `ClipPlayer` 介面驅動 WebView，
JVM 上用 `FakeClipPlayer` 加虛擬時間測。循環在頁面裡用注入的 JS 每 50 毫秒檢查，不靠 Kotlin 輪詢。

**Tech Stack:** Kotlin、Jetpack Compose（`HorizontalPager`、`AndroidView`）、Android WebView（YouTube embed／`m.youtube.com`）、kotlinx-coroutines（`runTest` 虛擬時間）、Robolectric。

**Spec:** `docs/superpowers/specs/2026-09-10-videoshot-app-design.md` 第六節「Lightbox（全屏檢視器）」底下的「自動播放片段」；第二節第 5 點（embed 要點封面才會播）；第六節「播放器」（WebView 釋放方式）。
驗收條目：`mockups/uiux-v2/驗收操作手冊.md` §三 最後四條〔app〕。

## Global Constraints

- 倒數 **2 秒**（`CLIP_DELAY_MS = 2000`）、片段長 **3 秒**（`CLIP_LENGTH_SEC = 3.0`），兩個常數放在 `:core`（`core/player/ClipTiming.kt`），要調手感只改它們。
- 有聲音；行動網路照樣自動播；沒有控制層、不收雙擊。
- 還沒載好就維持縮圖，**不出現任何提示、黑畫面或轉圈**；載不出來也不跳錯誤訊息。
- 對 YouTube 的抓取只走 `youtube` 模組（這裡經由 `container.wizardData.watchPage`）；**畫面與控制器不直接碰 WebView 以外的網路**。
- 整個 Lightbox **只有一個 WebView**，Lightbox 離開組合時照既有方式釋放（`stopLoading` → `about:blank` → `onPause` → `destroy`）。
- 非同步讀取回來要先算結果、再 `_state.update { it.copy(…) }`／寫 `MutableStateFlow`，不要把 suspend 呼叫寫在 `.copy(…)` 參數裡（AGENTS.md「慣例」，2026-10-02 的卡死教訓）。
- commit message 繁體中文、`類型(範圍): 描述`，結尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。
- 測試指令都在 `android/` 下跑。這台開發機若 PATH 上沒有 java，先把 `JAVA_HOME` 指到 Android Studio 內建的 `jbr` 目錄。

## Review Focus

1. **`at_sec` 在影片最後一秒內或超過總長**（片尾截的圖、watch page 的總長是整數秒被截掉小數）→ 仍要循環一段 ≥ 1 秒的合理範圍，不能變成長度 0 的瘋狂跳回。測試在 Task 1（`clipRange`）。
2. **連續快速左右滑、每張停不到 2 秒** → 只有最後停下的那一張會播，前面的工作不能在別張上開播或出聲。測試在 Task 2（`快速換頁只播最後一張`）。
3. **播著的那一張被刪掉**（Lightbox 自動跳下一張，`items` 換了但頁碼沒變）→ 舊的片段停下、新的那一張重新倒數。測試在 Task 4（`目前這張換成別張時重新倒數`）。
4. **預載到一半 Lightbox 被關掉或按了【播放這一段】**（WebView 被釋放）→ 不當機、不留聲音、不再對已 destroy 的 WebView 下指令。測試在 Task 2（`播放器拿掉後不再下指令`）。
5. **watch page 抓取丟例外**（不是回 `FETCH_FAILED`，而是 OkHttp 直接丟 IOException 之類）→ 當成這張不能播，維持縮圖；**失敗不記住**，下次停到這張再抓。測試在 Task 2（`來源丟例外當成不能播_下次再試`）。

```kotlin
package com.xenyaa.videoshot.core.player

/**
 * Lightbox 自動播放片段的手感（規格第六節「自動播放片段」）：停在一張圖多久才開始播。
 * 要調手感只改這裡。
 */
const val CLIP_DELAY_MS: Long = 2000L

/** 循環一段多長（秒）。 */
const val CLIP_LENGTH_SEC: Double = 3.0

/** 循環最短要多長；片尾剩不到這麼多時整段往前推。 */
const val CLIP_MIN_LENGTH_SEC: Double = 1.0

/** 片段循環的範圍 [startSec, endSec)。 */
data class ClipRange(val startSec: Double, val endSec: Double)

/**
 * 片段從哪裡播到哪裡。
 *
 * 一般是 [atSec] 起 [CLIP_LENGTH_SEC] 秒；超過片尾只播到片尾。片尾剩不到 [CLIP_MIN_LENGTH_SEC]
 * （片尾截的圖、或截圖秒數比 watch page 的整數總長還大）時整段往前推成最後 [CLIP_LENGTH_SEC] 秒，
 * 否則循環長度趨近 0，畫面會一直跳回。[durationSec] ≤ 0（讀不到總長）時不夾。
 */
fun clipRange(atSec: Double, durationSec: Double): ClipRange {
    val start = atSec.coerceAtLeast(0.0)
    if (durationSec <= 0.0) return ClipRange(start, start + CLIP_LENGTH_SEC)
    val end = minOf(start + CLIP_LENGTH_SEC, durationSec)
    if (end - start >= CLIP_MIN_LENGTH_SEC) return ClipRange(start, end)
    return ClipRange((durationSec - CLIP_LENGTH_SEC).coerceAtLeast(0.0), durationSec)
}
```

`ClipPlayer.kt`：

```kotlin
package com.xenyaa.videoshot.player

/** watch page 裡片段播放要的兩件事（規格第六節「自動播放片段」）。 */
data class ClipSource(val playableInEmbed: Boolean, val durationSec: Int)

/** 要播哪一張：用 [shotId] 分辨「同一張」，[videoId] 決定要不要換頁面。 */
data class ClipTarget(val shotId: Long, val videoId: String, val atSec: Double)

/** 片段播放要讀的三個值。讀不到（頁面還沒好、沒有 `<video>`）時是 [Unknown]。 */
data class ClipStatus(val currentSec: Double, val readyState: Int, val paused: Boolean) {
    companion object {
        val Unknown = ClipStatus(0.0, 0, paused = true)
    }
}

/**
 * Lightbox 自動播放片段的播放器（規格第六節「自動播放片段」）。比取圖第二步與詳情頁的 [Player] 簡單：
 * 沒有控制層、不讀寬高，但要能「靜音預載」與「在頁面裡循環」。
 *
 * 呼叫順序：[load]（換影片才需要）→ [cue] → 輪詢 [status] 到緩衝好 → [hold] → [startLoop]。
 */
interface ClipPlayer {
    /** 載入這支影片的頁面，**頁面載完才回來**。 */
    suspend fun load(videoId: String, playableInEmbed: Boolean)

    /** 停掉上一段的循環、靜音、跳到 [startSec]、開始播放讓它緩衝。可以重複呼叫。 */
    suspend fun cue(startSec: Double)

    /** 緩衝好了：暫停並跳回 [startSec]，仍然靜音。 */
    suspend fun hold(startSec: Double)

    /** 取消靜音，從 [startSec] 開始在 [startSec, endSec) 之間循環。 */
    suspend fun startLoop(startSec: Double, endSec: Double)

    suspend fun pause()

    suspend fun resume()

    suspend fun status(): ClipStatus
}
```

`FakeClipPlayer.kt`：

```kotlin
package com.xenyaa.videoshot.player

/**
 * 測試用的片段播放器：不碰網路、立刻回應。放在 main 的理由同 [FakePlayer]。
 *
 * 播放中每讀一次 [status]，目前秒數前進 0.1 秒——控制器靠「秒數在前進」判斷畫面真的出來了。
 */
class FakeClipPlayer : ClipPlayer {

    /** 依序記錄每一個呼叫，例如 `load:v1`、`cue:30.0`、`hold:30.0`、`loop:30.0-33.0`、`pause`、`resume`。 */
    val calls: MutableList<String> = mutableListOf()

    /** false：[cue] 之後 readyState 停在 0，模擬網路慢、一直沒緩衝好。 */
    var readyAfterCue: Boolean = true

    /** 非 null：[cue] 之後秒數停在這裡（模擬 YouTube 自己跳回片頭），直到下一次 [cue]。 */
    var cueLandsAt: Double? = null

    private var time = 0.0
    private var ready = 0
    private var paused = true

    override suspend fun load(videoId: String, playableInEmbed: Boolean) {
        calls += "load:$videoId"
        ready = 0
        paused = true
    }

    override suspend fun cue(startSec: Double) {
        calls += "cue:$startSec"
        time = cueLandsAt ?: startSec
        cueLandsAt = null
        ready = if (readyAfterCue) 4 else 0
        paused = false
    }

    override suspend fun hold(startSec: Double) {
        calls += "hold:$startSec"
        time = startSec
        paused = true
    }

    override suspend fun startLoop(startSec: Double, endSec: Double) {
        calls += "loop:$startSec-$endSec"
        time = startSec
        paused = false
    }

    override suspend fun pause() {
        calls += "pause"
        paused = true
    }

    override suspend fun resume() {
        calls += "resume"
        paused = false
    }

    /** 測試中途讓它緩衝好。 */
    fun becomeReady() { ready = 4 }

    override suspend fun status(): ClipStatus {
        if (!paused && ready > 0) time += 0.1
        return ClipStatus(time, ready, paused)
    }
}
```

package com.xenyaa.videoshot.player

import com.xenyaa.videoshot.core.player.CLIP_DELAY_MS
import com.xenyaa.videoshot.core.player.ClipRange
import com.xenyaa.videoshot.core.player.clipRange
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Job
import kotlinx.coroutines.async
import kotlinx.coroutines.coroutineScope
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.filterNotNull
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.launch

/** 預載與等畫面出來時讀 [ClipPlayer.status] 的間隔。 */
const val CLIP_POLL_MS: Long = 100L

/** 秒數超過起點這麼多才算「畫面真的在動」，才把縮圖淡掉。 */
private const val ADVANCE_EPS_SEC = 0.05

/** 預載時秒數落在起點前面超過這麼多，當成 YouTube 自己跳回片頭，再跳一次。 */
private const val CUE_DRIFT_SEC = 1.0

/**
 * Lightbox 自動播放片段的流程（規格第六節「自動播放片段」）。不碰 Compose，畫面只讀 [showing]／[userPaused]、
 * 把事件（停在某一張、開始拖、點一下、被蓋住）丟進來。
 *
 * 一次只有一個工作（[job]）：停在某一張就開一個，開始拖或換一張就取消。工作裡「倒數」與「預載」同時跑，
 * 兩個都完成才開始循環，等秒數真的在前進才把 [showing] 設成那張——畫面在那之前一直是縮圖。
 *
 * @param scope 畫面的 scope；Lightbox 離開組合時一起取消
 * @param source 抓 watch page 換成 [ClipSource]；拿不到回 null。**成功的結果記在這個物件裡**（這次 Lightbox），失敗不記
 */
class LightboxClipController(
    private val scope: CoroutineScope,
    private val source: suspend (videoId: String) -> ClipSource?,
    private val delayMs: Long = CLIP_DELAY_MS,
) {
    private val player = MutableStateFlow<ClipPlayer?>(null)
    private val covered = MutableStateFlow(false)
    private val sources = mutableMapOf<String, ClipSource>()

    /** 頁面上目前載的是哪支影片；load 完成才寫，中途被取消就保持 null，下次一定重載。 */
    private var loadedVideoId: String? = null
    private var job: Job? = null

    /** 已經下過 startLoop：之後被蓋住、點一下才需要對播放器下暫停／繼續。 */
    private var loopStarted = false

    private val _showing = MutableStateFlow<Long?>(null)

    /** 正在顯示影片的那一張的 shotId；null＝顯示縮圖。 */
    val showing: StateFlow<Long?> = _showing

    private val _userPaused = MutableStateFlow(false)
    val userPaused: StateFlow<Boolean> = _userPaused

    /** WebView 建好給播放器；被釋放時給 null——之後不能再對它下任何指令（Review Focus 4）。 */
    fun attach(p: ClipPlayer?) {
        if (p == null) reset()
        loadedVideoId = null
        player.value = p
    }

    /** 停在某一張（含剛開啟、滑回同一張、目前這張被刪掉換成下一張）：重新倒數。 */
    fun onSettled(target: ClipTarget) {
        reset()
        job = scope.launch { run(target) }
    }

    /** 手指開始拖：倒數作廢、影片立刻暫停、換回縮圖。 */
    fun onDragStart() {
        reset()
        val p = player.value ?: return
        scope.launch { p.pause() }
    }

    /** 點一下影片：暫停／繼續。還是縮圖時沒反應。 */
    fun onTap() {
        if (_showing.value == null) return
        _userPaused.value = !_userPaused.value
        applyPlayback()
    }

    /** ⋯ 選單、確認框、抽屜、切到背景。 */
    fun setCovered(value: Boolean) {
        if (covered.value == value) return
        covered.value = value
        if (loopStarted) applyPlayback()
    }

    private fun reset() {
        job?.cancel()
        job = null
        loopStarted = false
        _showing.value = null
        _userPaused.value = false
    }

    private fun applyPlayback() {
        val p = player.value ?: return
        val play = !_userPaused.value && !covered.value
        scope.launch { if (play) p.resume() else p.pause() }
    }

    private suspend fun run(target: ClipTarget) = coroutineScope {
        val prepared = async { prepare(target) }
        delay(delayMs)
        val range = prepared.await() ?: return@coroutineScope
        covered.first { !it }
        val p = player.value ?: return@coroutineScope
        loopStarted = true
        p.startLoop(range.startSec, range.endSec)
        while (true) {
            val s = p.status()
            if (!s.paused && s.currentSec > range.startSec + ADVANCE_EPS_SEC) break
            delay(CLIP_POLL_MS)
        }
        _showing.value = target.shotId
    }

    /** 抓來源 → 換頁面（不同影片才換）→ 靜音預載到起點 → 停住。拿不到來源回 null。 */
    private suspend fun prepare(target: ClipTarget): ClipRange? {
        val src = sources[target.videoId]
            ?: fetch(target.videoId)?.also { sources[target.videoId] = it }
            ?: return null
        val p = player.filterNotNull().first()
        if (loadedVideoId != target.videoId) {
            loadedVideoId = null
            p.load(target.videoId, src.playableInEmbed)
            loadedVideoId = target.videoId
        }
        val range = clipRange(target.atSec, src.durationSec.toDouble())
        p.cue(range.startSec)
        while (true) {
            val s = p.status()
            if (s.readyState >= 3 && s.currentSec >= range.startSec) break
            if (s.readyState >= 1 && s.currentSec < range.startSec - CUE_DRIFT_SEC) p.cue(range.startSec)
            delay(CLIP_POLL_MS)
        }
        p.hold(range.startSec)
        return range
    }

    private suspend fun fetch(videoId: String): ClipSource? = try {
        source(videoId)
    } catch (c: CancellationException) {
        throw c
    } catch (_: Exception) {
        null
    }
}
```

注意 `attach(null)` 之後 `player.value` 是 null，`onDragStart`／`applyPlayback` 都會直接 return；`reset()` 取消的工作若正在 `p.status()` 迴圈裡，下一次 `delay` 就被取消，不會再下指令。

import android.annotation.SuppressLint

/**
 * Lightbox 片段播放器的 WebView 實作（規格第六節「自動播放片段」）。網址、藏介面、點封面開播都沿用
 * [WebViewPlayer] 那一套（規格第二節第 5 點）；多的是靜音預載與在頁面裡循環。
 */
class WebViewClipPlayer(private val webView: WebView) : ClipPlayer {

    private var pageLoaded = CompletableDeferred<Unit>()

    /** `onPageFinished` 呼叫。 */
    internal fun onPageFinished() { pageLoaded.complete(Unit) }

    override suspend fun load(videoId: String, playableInEmbed: Boolean) {
        val done = CompletableDeferred<Unit>()
        pageLoaded = done
        val url = playerUrl(videoId, playableInEmbed)
        // embed 需要 referer，否則部分影片會拒絕播放（同 PlayerSurface）
        webView.post { webView.loadUrl(url, mapOf("Referer" to "https://${webView.context.packageName}")) }
        done.await()
    }

    override suspend fun cue(startSec: Double) { eval(clipCueJs(startSec)) }
    override suspend fun hold(startSec: Double) { eval(clipHoldJs(startSec)) }
    override suspend fun startLoop(startSec: Double, endSec: Double) { eval(clipLoopJs(startSec, endSec)) }
    override suspend fun pause() { eval(PAUSE_VIDEO_JS) }
    override suspend fun resume() { eval(CLIP_RESUME_JS) }
    override suspend fun status(): ClipStatus = parseClipStatus(eval(CLIP_STATUS_JS))

    private suspend fun eval(js: String): String = suspendCancellableCoroutine { cont ->
        webView.post { webView.evaluateJavascript(js) { if (cont.isActive) cont.resume(it ?: "") } }
    }
}

/** 封面播放鍵的選擇器，同 `PLAY_VIDEO_JS`（行動版 embed 與桌機版兩種 DOM；**不要加 `.ytp-play-button`**）。 */
private const val COVER_SELECTOR =
    "'.ytmCuedOverlayPlayButton, [class*=\"CuedOverlayPlayButton\"], .ytp-large-play-button'"

/**
 * 預載：停掉上一段的循環、靜音、跳到起點、開始播讓它緩衝。
 * 還沒開播（`readyState=0`）時 `v.play()` 沒有用，要點封面（規格第二節第 5 點）；
 * 那時設定的 `currentTime` 會成為起播位置。
 */
internal fun clipCueJs(startSec: Double): String =
    """
    (function(){
      if (window.__vsLoop) { clearInterval(window.__vsLoop); window.__vsLoop = null; }
      var v = document.querySelector('video');
      if (v) { v.muted = true; v.currentTime = $startSec; }
      if (!v || v.readyState === 0) {
        var o = document.querySelector($COVER_SELECTOR);
        if (o) { o.click(); return 'overlay'; }
      }
      if (v) { v.play(); return 'play'; }
      return 'none';
    })()
    """.trimIndent()

/** 緩衝好了：停住、跳回起點，仍然靜音。 */
internal fun clipHoldJs(startSec: Double): String =
    "(function(){var v=document.querySelector('video'); if(!v) return 'none'; v.pause(); v.currentTime = $startSec; return 'ok';})()"

/**
 * 開始循環：在頁面裡每 50 毫秒檢查一次，到終點、跑到起點以前、或播到片尾停住（`ended`）就跳回起點。
 * 不靠 Kotlin 輪詢——那樣一來一回 0.25 秒，循環點會晃。`__vsLoop` 只留一個。
 */
internal fun clipLoopJs(startSec: Double, endSec: Double): String =
    """
    (function(){
      var v = document.querySelector('video');
      if (!v) return 'none';
      if (window.__vsLoop) clearInterval(window.__vsLoop);
      window.__vsLoop = setInterval(function(){
        var v = document.querySelector('video');
        if (!v) return;
        if (v.ended || v.currentTime >= $endSec || v.currentTime < $startSec - 0.5) {
          var again = v.ended;
          v.currentTime = $startSec;
          if (again) v.play();
        }
      }, 50);
      v.currentTime = $startSec;
      v.muted = false;
      v.play();
      return 'ok';
    })()
    """.trimIndent()

internal const val CLIP_RESUME_JS =
    "(function(){var v=document.querySelector('video'); if(v) v.play(); return 'ok';})()"

/** currentTime, readyState, paused，逗號隔開（同 `STATUS_JS` 的理由）。 */
internal const val CLIP_STATUS_JS =
    "(function(){var v=document.querySelector('video'); if(!v) return 'none'; return [v.currentTime, v.readyState, v.paused ? 1 : 0].join(',');})()"

/**
 * 頁面背景透明，影片外的留白才會露出 Lightbox 的底色。`BARE_PLAYER_JS` 把 html／body 設成 #000!important，
 * 這條同樣 !important、晚注入，所以蓋得過。
 */
internal val CLIP_TRANSPARENT_JS =
    """
    (function(){
      if (document.getElementById('vs-clip-bg')) return 'exists';
      var s = document.createElement('style');
      s.id = 'vs-clip-bg';
      s.textContent = 'html,body{background:transparent!important}';
      (document.head || document.documentElement).appendChild(s);
      return 'ok';
    })()
    """.trimIndent()

internal fun parseClipStatus(raw: String): ClipStatus {
    val parts = raw.trim().removeSurrounding("\"").split(',')
    if (parts.size != 3) return ClipStatus.Unknown
    val current = parts[0].toDoubleOrNull()?.takeIf { it.isFinite() } ?: return ClipStatus.Unknown
    val ready = parts[1].toDoubleOrNull()?.toInt() ?: return ClipStatus.Unknown
    return ClipStatus(current, ready, paused = parts[2].trim() != "0")
}

/**
 * Lightbox 的片段播放器（一個 Lightbox 只有一個）。WebView 不收觸控、不收焦點——左右滑與點一下都由
 * 疊在上面的 pager 處理（規格第六節「自動播放片段」→「實作要點」）。
 *
 * @param alpha 0＝藏起來（預載中），1＝露出來；直接設在 View 上，淡入淡出由呼叫端算
 * @param onPlayer WebView 建好時給播放器、釋放時給 null
 */
@SuppressLint("SetJavaScriptEnabled", "ClickableViewAccessibility")
@Composable
fun ClipPlayerSurface(
    alpha: Float,
    onPlayer: (ClipPlayer?) -> Unit,
    modifier: Modifier = Modifier,
) {
    val currentOnPlayer = rememberUpdatedState(onPlayer)
    val holder = remember { arrayOfNulls<WebView>(1) }

    val lifecycleOwner = LocalLifecycleOwner.current
    DisposableEffect(lifecycleOwner) {
        val observer = LifecycleEventObserver { _, event ->
            when (event) {
                // 切到背景聲音要停；回來時要不要繼續播由控制器決定（Lightbox 的 covered）
                Lifecycle.Event.ON_PAUSE -> holder[0]?.let { it.evaluateJavascript(PAUSE_VIDEO_JS, null); it.onPause() }
                Lifecycle.Event.ON_RESUME -> holder[0]?.onResume()
                else -> Unit
            }
        }
        lifecycleOwner.lifecycle.addObserver(observer)
        onDispose { lifecycleOwner.lifecycle.removeObserver(observer) }
    }

    AndroidView(
        modifier = modifier,
        factory = { context ->
            WebView(context).apply {
                applyPlayerViewSettings()
                setBackgroundColor(Color.TRANSPARENT)
                webChromeClient = WebChromeClient()
                val clip = WebViewClipPlayer(this)
                webViewClient = object : WebViewClient() {
                    override fun onPageCommitVisible(view: WebView?, url: String?) {
                        view?.evaluateJavascript(BARE_PLAYER_JS, null)
                        view?.evaluateJavascript(CLIP_TRANSPARENT_JS, null)
                    }

                    override fun onPageFinished(view: WebView?, url: String?) {
                        view?.evaluateJavascript(BARE_PLAYER_JS, null)
                        view?.evaluateJavascript(CLIP_TRANSPARENT_JS, null)
                        clip.onPageFinished()
                    }
                }
                setOnTouchListener { _, _ -> true }
                isFocusable = false
                isFocusableInTouchMode = false
                importantForAccessibility = android.view.View.IMPORTANT_FOR_ACCESSIBILITY_NO_HIDE_DESCENDANTS
                holder[0] = this
                currentOnPlayer.value(clip)
            }
        },
        update = { it.alpha = alpha },
        onRelease = { webView ->
            holder[0] = null
            currentOnPlayer.value(null)
            // 先卸掉頁面再 destroy：about:blank 會把 <video> 一起帶走，聲音當場停（同 PlayerSurface）
            webView.stopLoading()
            webView.loadUrl("about:blank")
            webView.onPause()
            webView.destroy()
        },
    )
}
```
