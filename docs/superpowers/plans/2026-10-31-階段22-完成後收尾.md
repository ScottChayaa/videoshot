# 階段 22：剪輯完成後收尾 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目標：** 點剪輯頁「已完成」的任務，在導出中畫面問要不要刪除這次用到的照片與影片（`MediaStore.createDeleteRequest`，有媒體管理權限就不跳系統視窗），接著直接進取圖精靈第二步開這支 YouTube 影片；進了第二步任務就從清單移除、紅點減一。

**架構：** 刪除原檔走 `media` 模組新增的 `MediaDeleter`（規格邊界 6：本機相片與影片的讀取、刪除只走 `media`）。導出中畫面的「已完成」狀態從佔位字換成刪除提醒；流程的接線（問別支草稿 → 系統刪除視窗 → 進精靈）放在 `ClipExportRoute`，進精靈與移除任務在 `AppRoot`。取圖精靈多兩個入口函式：`otherDraft(videoId)`（有沒有別支影片的草稿）與 `openFromClip(videoId)`（放棄別支草稿、開這支到第二步，回傳有沒有進到第二步）。不動資料庫結構（`edit_task` 進第二步就刪那一列，規格第十九節「資料」本來就這樣寫）。

**技術：** Kotlin、Compose、`MediaStore.createDeleteRequest`（API 30）、`MediaStore.canManageMedia`／`Settings.ACTION_REQUEST_MANAGE_MEDIA`（API 31）、`ActivityResultContracts.StartIntentSenderForResult`、Robolectric、實機（2107113SG，Android 12）。

**規格：** [`../specs/2026-09-10-videoshot-app-design.md`](../specs/2026-09-10-videoshot-app-design.md) 第十九節「完成後」「選素材」（部分允許的 ⏳）「背景任務」（導出中畫面、刪除與取消、通知）「資料」「架構」；第五節「入口」「流程總覽」「草稿：中途離開」；路線圖[階段 22](2026-09-11-videoshot-android-實作計畫.md)；階段 21 的[計畫](2026-10-29-階段21-上傳到YouTube.md)與[開發紀錄](../../開發紀錄/階段21-剪輯上傳到YouTube.md)。

## scott 的決定（2026-10-31）

1. **提醒放在導出中畫面的「已完成」狀態**：沿用現在點任務進去的那個畫面，「已上傳到 YouTube（非公開）」＋〈標題〉下面，把「開始取圖在下一個階段加入」換成問句與兩個按鈕；規格說的「關閉（不處理，任務留在已完成）」就是左上角返回。
2. **先問草稿、再刪除**（改規格原本的順序）：按【刪除並開始取圖】或【保留並開始取圖】時，精靈有別支影片的草稿就先問「取圖還有未完成的〈標題〉，要放棄它嗎？」；按【取消】什麼都沒發生（沒刪、沒換頁、任務仍是已完成）。
3. **Android 14 只允許部分相片時照樣交給系統刪除視窗**（規格「選素材」那條 ⏳ 改定案）：app 看不到的素材（沒被允許的那些）當作不在手機裡、不列入、不刪；刪不掉就略過，照樣進取圖。實機是 Android 12，記進已知缺口「沒在實機驗過」。
4. **Android 9、10 不提供刪除**：`createDeleteRequest` 是 Android 11 才有，9、10 的已完成畫面只有【開始取圖】。
5. **「不想每次確認？【開啟媒體管理權限】」只要還沒開就一直顯示**（Android 12 起），開了就消失；不另外記「刪過了沒」。
6. **這次用到的素材全都已不在手機裡時不問刪除**，只留一個【開始取圖】、不加說明；部分還在時問句只算還在的。

## 審查重點

1. **系統刪除視窗按拒絕或返回**：不刪、照樣進第二步、任務移除；不能卡在導出中畫面。（Task 5 的測試以「拿不到視窗」代替，實機在 Task 6 按拒絕）

3. **素材部分或全部已不在手機上**：問句只算還在的；全不在只剩【開始取圖】；交給 `createDeleteRequest` 的不含已不存在的 URI。（Task 2、Task 4 的測試）
4. **別支草稿按【放棄並繼續】**：舊草稿刪完才開新影片，舊草稿的清理不會把新影片剛存的草稿清掉（`clearDraft` 是整列刪）；按【取消】什麼都不動。（Task 3、Task 5 的測試）
