# 播放器控制層與全螢幕 實作計畫

> **給代理人：** 必用子技能：superpowers:subagent-driven-development（建議）或 superpowers:executing-plans，逐任務執行。步驟用勾選框（`- [ ]`）追蹤。
> 回報與報告檔一律用繁體中文。

**目標：** 取圖第二步與詳情頁的播放器改成只留影片畫面＋app 自己的控制層（點一下叫出、點兩下播放暫停、拖曳跳播帶預覽、全螢幕），整個 app 鎖定直立。

**架構：** 純邏輯（拖曳換算、橫直判斷、最近格子、限高）放 `:core`。`Player` 介面多一個 `status()`／`togglePlay()`。
控制層是獨立的 Composable `PlayerControls`（不碰 WebView，可在 Robolectric 測），由 `PlayerSurface` 疊在 WebView 上。
全螢幕狀態是一個 `PlayerFullscreenState`，用 CompositionLocal 從 `MainActivity` 往下發；`MainActivity` 依它設定方向與沉浸模式，
各畫面依它把其他東西藏起來、播放器原地放大（不搬位置，WebView 才不會重建）。

**技術：** Kotlin、Jetpack Compose（`pointerInput`、`detectTapGestures`、`detectHorizontalDragGestures`）、`WindowInsetsControllerCompat`、Robolectric。

**規格：** [`docs/superpowers/specs/2026-09-10-videoshot-app-design.md`](../specs/2026-09-10-videoshot-app-design.md) 第六節「播放器（取圖第二步與詳情頁共用）」；
驗收：[`mockups/uiux-v2/驗收操作手冊.md`](../../../mockups/uiux-v2/驗收操作手冊.md) §零、§四第二步、§七。

## 全域限制

- 敏感度常數 `SCRUB_SENSITIVITY = 1.0`；換算：`跳的秒數 ＝ 水平移動距離 ÷ 播放器寬 × 影片總長 × 敏感度`，夾在 0 到總長。
- 橫的影片：寬高比 **≥ 1.3**；讀不到寬高當成橫的。
- 控制層 **3 秒**沒有操作就收起；**暫停中不自動收起**；拖曳中不收起。
- 進度條：收起時 **2dp**，打開時 **4dp**＋圓形把手＋左右時間文字（`formatClock`）。
- Android 16 以上大螢幕橫向時（視窗寬 > 高），非全螢幕的播放器高度上限＝視窗高度 **40%**。
- 詳情頁預覽 sheet 放 `cacheDir/preview/{videoId}/L{level}/M{n}.jpg`，層級 `Storyboard.pickLevel(spec, preferred = 2)`。
- 程式碼註解用繁體中文、照周圍密度；commit 格式 `類型(範圍): 描述`＋條列，**不加 Co-Authored-By 等署名**。

```kotlin
package com.xenyaa.videoshot.core.player

import com.xenyaa.videoshot.core.storyboard.Storyboard
import com.xenyaa.videoshot.core.storyboard.StoryboardLevel
import com.xenyaa.videoshot.core.storyboard.StoryboardSpec
import kotlin.math.abs

/**
 * 拖曳跳播的敏感度（規格第六節「播放器」）：1.0 ＝ 滑過整個播放器寬度跳整支影片。
 * 之後要調手感只改這一個數字。
 */
const val SCRUB_SENSITIVITY: Double = 1.0

/** 橫的影片的門檻：16:9、4:3 都算橫的，正方形與直的不算。 */
private const val LANDSCAPE_RATIO = 1.3

/** 大螢幕橫向時，非全螢幕播放器最多占視窗高度的比例（Android 16 以上鎖不住直立）。 */
private const val LANDSCAPE_MAX_HEIGHT_FRACTION = 0.4f

/**
 * 拖曳後要跳到的秒數：從拖曳開始時的 [startSec] 起算，夾在 0 到總長。
 * 寬度或總長不合理（0、負數）時原地不動。
 */
fun scrubTargetSec(
    startSec: Double,
    dxPx: Float,
    widthPx: Float,
    durationSec: Double,
    sensitivity: Double = SCRUB_SENSITIVITY,
): Double {
    if (widthPx <= 0f || durationSec <= 0.0) return startSec
    val delta = dxPx / widthPx * durationSec * sensitivity
    return (startSec + delta).coerceIn(0.0, durationSec)
}

/** 全螢幕要不要轉橫向。讀不到寬高（還沒開播）當成橫的——大部分影片是橫的。 */
fun isLandscapeVideo(width: Int?, height: Int?): Boolean {
    if (width == null || height == null || width <= 0 || height <= 0) return true
    return width.toDouble() / height >= LANDSCAPE_RATIO
}

/** 跟 [sec] 最接近的那一格；沒有格子回 null。 */
fun nearestFrameIndex(atSec: List<Double>, sec: Double): Int? =
    atSec.indices.minByOrNull { abs(atSec[it] - sec) }

/** 橫向視窗（寬 > 高）時播放器的高度上限；直向回 null（不限）。 */
fun playerMaxHeightDp(windowWidthDp: Float, windowHeightDp: Float): Float? =
    if (windowWidthDp > windowHeightDp) windowHeightDp * LANDSCAPE_MAX_HEIGHT_FRACTION else null

/** 詳情頁預覽用的層級：比第二步的 L3 低一階，檔案小、下載快。 */
fun previewLevelOf(spec: StoryboardSpec): StoryboardLevel? = Storyboard.pickLevel(spec, preferred = 2)
```

```kotlin
/**
 * 一次讀完控制層要的六個值，逗號隔開（不用 JSON.stringify：回來還要再剝一層引號跟跳脫，逗號字串最好解）。
 * 順序：currentTime, duration, paused, readyState>0, videoWidth, videoHeight。
 */
internal val STATUS_JS =
    """
    (function(){
      var v = document.querySelector('video');
      if (!v) return 'none';
      return [v.currentTime, v.duration, v.paused ? 1 : 0, v.readyState > 0 ? 1 : 0, v.videoWidth, v.videoHeight].join(',');
    })()
    """.trimIndent()

/** [STATUS_JS] 的回傳值。格式不對一律當未知，不丟例外——控制層讀不到只是不顯示，不該當機。 */
internal fun parseStatus(raw: String): PlaybackStatus {
    val parts = raw.trim().removeSurrounding("\"").split(',')
    if (parts.size != 6) return PlaybackStatus.Unknown
    val nums = parts.map { it.toDoubleOrNull() }
    val current = nums[0] ?: return PlaybackStatus.Unknown
    val duration = nums[1]?.takeIf { !it.isNaN() && !it.isInfinite() } ?: 0.0
    return PlaybackStatus(
        currentSec = current,
        durationSec = duration,
        paused = nums[2] != 0.0,
        started = nums[3] == 1.0,
        videoWidth = nums[4]?.toInt() ?: 0,
        videoHeight = nums[5]?.toInt() ?: 0,
    )
}
```

```kotlin
/** 播放中控制層沒人碰多久自己收起（規格第六節「播放器」）。 */
const val CONTROLS_AUTO_HIDE_MS = 3_000L

/** 點兩下時中央閃一下的圖示停多久。 */
private const val FLASH_MS = 600L

/** TalkBack 一次前後跳幾秒。 */
private const val A11Y_STEP_SEC = 10.0

internal const val PLAYER_GESTURE_TAG = "player-gestures"
internal const val PREVIEW_BUBBLE_TAG = "player-preview"

/**
 * 蓋在影片上的控制層（規格第六節「播放器」）。只管畫面與手勢，不碰 WebView：
 * 狀態從 [status] 進來，動作從回呼出去，所以可以在 Robolectric 裡單獨測。
 *
 * @param fallbackDurationSec `<video>.duration` 還沒有值（沒開播）時用 watch page 的總長
 * @param enabled 播放器還沒載好時 false：手勢都不作用、控制層不出現
 * @param preview 第 N 秒的預覽圖；拿不到回 null，預覽泡泡只顯示時間
 */
@Composable
fun PlayerControls(
    status: PlaybackStatus,
    fallbackDurationSec: Double,
    enabled: Boolean,
    fullscreen: Boolean,
    preview: suspend (Double) -> ImageBitmap?,
    onTogglePlay: () -> Unit,
    onSeek: (Double) -> Unit,
    onToggleFullscreen: () -> Unit,
    modifier: Modifier = Modifier,
) {
    val duration = status.durationSec.takeIf { it > 0 } ?: fallbackDurationSec
    var visible by remember { mutableStateOf(false) }
    // 每次有操作就 +1，讓自動收起的計時重來
    var touches by remember { mutableIntStateOf(0) }
    var dragSec by remember { mutableStateOf<Double?>(null) }
    var flash by remember { mutableStateOf<Boolean?>(null) }   // true＝播放圖示、false＝暫停圖示

    val latestStatus by rememberUpdatedState(status)
    val latestDuration by rememberUpdatedState(duration)
    val latestEnabled by rememberUpdatedState(enabled)

    // 播放中、沒在拖、3 秒沒人碰 → 收起；暫停中一直留著
    LaunchedEffect(visible, status.paused, touches, dragSec == null) {
        if (visible && !status.paused && dragSec == null) {
            delay(CONTROLS_AUTO_HIDE_MS)
            visible = false
        }
    }
    LaunchedEffect(flash) {
        if (flash != null) { delay(FLASH_MS); flash = null }
    }

    val position = dragSec ?: status.currentSec
    val fraction = if (duration > 0) (position / duration).toFloat().coerceIn(0f, 1f) else 0f

    BoxWithConstraints(modifier) {
        val widthPx = constraints.maxWidth.toFloat()
        Box(
            Modifier
                .fillMaxSize()
                .testTag(PLAYER_GESTURE_TAG)
                .semantics {
                    contentDescription = "影片"
                    onClick(label = if (visible) "隱藏控制項" else "顯示控制項") {
                        if (latestEnabled) visible = !visible
                        latestEnabled
                    }
                }
                .pointerInput(Unit) {
                    detectTapGestures(
                        onTap = { if (latestEnabled) { visible = !visible; touches++ } },
                        onDoubleTap = {
                            if (latestEnabled) {
                                flash = latestStatus.paused   // 原本暫停 → 要播 → 閃播放圖示
                                onTogglePlay()
                                touches++
                            }
                        },
                    )
                }
                .pointerInput(Unit) {
                    var startSec = 0.0
                    var dx = 0f
                    detectHorizontalDragGestures(
                        onDragStart = {
                            if (latestEnabled && latestDuration > 0) {
                                startSec = latestStatus.currentSec
                                dx = 0f
                                dragSec = startSec
                                visible = true
                            }
                        },
                        onHorizontalDrag = { change, amount ->
                            if (dragSec != null) {
                                change.consume()
                                dx += amount
                                dragSec = scrubTargetSec(startSec, dx, widthPx, latestDuration)
                            }
                        },
                        onDragEnd = {
                            dragSec?.let(onSeek)
                            dragSec = null
                            touches++
                        },
                        onDragCancel = { dragSec = null },
                    )
                },
        )

        // 半透明底＋中央按鈕＋全螢幕鈕
        AnimatedVisibility(visible && enabled, enter = fadeIn(), exit = fadeOut()) {
            Box(Modifier.fillMaxSize().background(Color.Black.copy(alpha = 0.35f))) {
                if (dragSec == null) {
                    IconButton(
                        onClick = { onTogglePlay(); touches++ },
                        modifier = Modifier.align(Alignment.Center).size(64.dp),
                    ) {
                        Icon(
                            if (status.paused) VsIcons.Play else VsIcons.Pause,
                            contentDescription = if (status.paused) "播放" else "暫停",
                            tint = OnDarkColors.primary,
                            modifier = Modifier.size(40.dp),
                        )
                    }
                }
                IconButton(
                    onClick = { onToggleFullscreen(); touches++ },
                    modifier = Modifier.align(Alignment.BottomEnd).padding(bottom = 12.dp),
                ) {
                    Icon(
                        if (fullscreen) VsIcons.Minimize else VsIcons.Maximize,
                        contentDescription = if (fullscreen) "離開全螢幕" else "全螢幕",
                        tint = OnDarkColors.primary,
                    )
                }
                Row(
                    Modifier.align(Alignment.BottomStart).padding(start = 12.dp, bottom = 22.dp),
                ) {
                    Text(
                        "${formatClock(position)} / ${formatClock(duration)}",
                        style = MaterialTheme.typography.labelSmall,
                        color = OnDarkColors.primary,
                    )
                }
            }
        }

        // 點兩下時中央閃一下
        flash?.let { playing ->
            Icon(
                if (playing) VsIcons.Play else VsIcons.Pause,
                contentDescription = null,
                tint = OnDarkColors.primary,
                modifier = Modifier.align(Alignment.Center).size(48.dp)
                    .background(Color.Black.copy(alpha = 0.4f), CircleShape).padding(8.dp),
            )
        }

        // 拖曳預覽泡泡：跟著進度條位置走，夾在畫面內
        dragSec?.let { sec ->
            val bubbleWidth = 160.dp
            val maxOffset = maxWidth - bubbleWidth
            val x = (maxWidth * fraction - bubbleWidth / 2).coerceIn(0.dp, maxOffset.coerceAtLeast(0.dp))
            PreviewBubble(sec, preview, Modifier.align(Alignment.BottomStart).offset(x = x, y = (-28).dp).width(bubbleWidth))
        }

        ProgressBar(
            fraction = fraction,
            thick = visible && enabled,
            duration = duration,
            position = position,
            onSeek = { onSeek(it); touches++ },
            modifier = Modifier.align(Alignment.BottomCenter).fillMaxWidth(),
        )
    }
}

/** 下緣進度條：收起時 2dp 細線；控制層打開時 4dp＋圓形把手（規格第六節）。宣告成 TalkBack 滑桿。 */
@Composable
private fun ProgressBar(
    fraction: Float,
    thick: Boolean,
    duration: Double,
    position: Double,
    onSeek: (Double) -> Unit,
    modifier: Modifier = Modifier,
) {
    val barHeight: Dp = if (thick) 4.dp else 2.dp
    BoxWithConstraints(
        modifier
            .height(if (thick) 16.dp else 2.dp)
            .semantics {
                contentDescription = "播放進度"
                progressBarRangeInfo = ProgressBarRangeInfo(position.toFloat(), 0f..duration.toFloat().coerceAtLeast(0f))
                if (duration > 0) {
                    setProgress { target -> onSeek(target.toDouble().coerceIn(0.0, duration)); true }
                    customActions = listOf(
                        CustomAccessibilityAction("往後 10 秒") { onSeek((position + A11Y_STEP_SEC).coerceAtMost(duration)); true },
                        CustomAccessibilityAction("往前 10 秒") { onSeek((position - A11Y_STEP_SEC).coerceAtLeast(0.0)); true },
                    )
                }
            },
        contentAlignment = Alignment.BottomStart,
    ) {
        Box(Modifier.fillMaxWidth().height(barHeight).background(OnDarkColors.tertiary.copy(alpha = 0.4f)))
        Box(Modifier.fillMaxWidth(fraction).height(barHeight).background(AppTheme.colors.accent))
        if (thick) {
            Box(
                Modifier
                    .offset(x = maxWidth * fraction - 6.dp, y = 4.dp)
                    .size(12.dp)
                    .clip(CircleShape)
                    .background(AppTheme.colors.accent),
            )
        }
    }
}

            )
        }

            formatClock(sec),
            style = MaterialTheme.typography.labelMedium,
            color = OnDarkColors.primary,
            modifier = Modifier.padding(top = 4.dp)
                .background(Color.Black.copy(alpha = 0.6f), RoundedCornerShape(4.dp))
                .padding(horizontal = 6.dp, vertical = 2.dp),
        )
    }
}
```

```kotlin
package com.xenyaa.videoshot.player

import android.app.Activity
import android.content.Context
import android.content.ContextWrapper
import android.content.pm.ActivityInfo
import androidx.compose.runtime.Composable
import androidx.compose.runtime.DisposableEffect
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import androidx.compose.runtime.staticCompositionLocalOf
import androidx.compose.ui.platform.LocalContext
import androidx.core.view.WindowCompat
import androidx.core.view.WindowInsetsCompat
import androidx.core.view.WindowInsetsControllerCompat

/**
 * 播放器全螢幕（規格第六節「全螢幕與畫面方向」）。整個 app 只有一份，由 `MainActivity` 發下去：
 * [FullscreenSystemEffect] 依它設方向與系統列，各畫面依它把播放器以外的東西藏起來。
 *
 * **全螢幕不是另開畫面**：播放器在組合裡的位置不能變，WebView 才不會被銷毀重載。
 */
class PlayerFullscreenState {
    var active by mutableStateOf(false)
        private set
    var landscape by mutableStateOf(true)
        private set

    fun enter(landscape: Boolean) {
        this.landscape = landscape
        active = true
    }

    fun exit() { active = false }
}

/** 預設值給預覽與測試用；正式畫面一律由 `MainActivity` 提供同一份。 */
val LocalPlayerFullscreen = staticCompositionLocalOf { PlayerFullscreenState() }

/**
 * 平常鎖直立；橫的影片全螢幕時轉橫向（兩個橫向都接受）。
 * Android 16 以上的大螢幕系統會忽略這個要求（規格第六節），不用另外判斷。
 */
internal fun orientationFor(active: Boolean, landscape: Boolean): Int =
    if (active && landscape) ActivityInfo.SCREEN_ORIENTATION_SENSOR_LANDSCAPE
    else ActivityInfo.SCREEN_ORIENTATION_PORTRAIT

/** 把 [state] 套到 Activity：方向＋沉浸模式（從邊緣滑一下暫時叫出系統列）。 */
@Composable
fun FullscreenSystemEffect(state: PlayerFullscreenState) {
    val activity = LocalContext.current.findActivity() ?: return
    LaunchedEffect(state.active, state.landscape) {
        activity.requestedOrientation = orientationFor(state.active, state.landscape)
        val controller = WindowCompat.getInsetsController(activity.window, activity.window.decorView)
        if (state.active) {
            controller.systemBarsBehavior = WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE
            controller.hide(WindowInsetsCompat.Type.systemBars())
        } else {
            controller.show(WindowInsetsCompat.Type.systemBars())
        }
    }
    // Activity 結束時不留任何狀態（方向本來就跟著 Activity 走，這裡只是保險）
    DisposableEffect(Unit) { onDispose { state.exit() } }
}

private tailrec fun Context.findActivity(): Activity? = when (this) {
    is Activity -> this
    is ContextWrapper -> baseContext.findActivity()
    else -> null
}
```

```kotlin
private const val STATUS_POLL_MS = 250L

/**
 * 播放器的外框（規格第六節）：非全螢幕時寬滿、16:9，大螢幕橫向（Android 16 以上鎖不住直立）時
 * 高度最多 40%，影片在框裡置中、兩側黑邊；全螢幕時撐滿。
 * **呼叫端只能換這個 Modifier，不能把播放器搬到別的位置**——搬了 WebView 就會重建。
 */
@Composable
fun Modifier.playerFrame(fullscreen: Boolean): Modifier {
    if (fullscreen) return this.fillMaxSize().background(Color.Black)
    val config = LocalConfiguration.current
    val maxH = playerMaxHeightDp(config.screenWidthDp.toFloat(), config.screenHeightDp.toFloat())
    val base = this.fillMaxWidth().background(Color.Black)
    return if (maxH == null) base.aspectRatio(16f / 9f)
    else base.heightIn(max = maxH.dp).aspectRatio(16f / 9f, matchHeightConstraintsFirst = true)
}
```

> `aspectRatio(matchHeightConstraintsFirst = true)` 讓高度先被上限夾住、寬度跟著縮——但外層 `fillMaxWidth` 已經把寬度撐滿，結果是「框寬滿、高度 40%」。WebView 的 `<video>` 已經 `object-fit:contain`（`BARE_PLAYER_JS`），所以影片在框內置中、兩側黑邊，正是規格要的樣子。若實測框沒有撐滿寬度，改成外包一層 `Box(Modifier.fillMaxWidth().heightIn(max=…))`、播放器 `fillMaxSize()`。

```kotlin
        assertNull(frames(FakeYoutube { throw java.io.IOException("斷線") }).at(0.0))
    }
```

```kotlin
package com.xenyaa.videoshot.player

import android.graphics.Bitmap
import android.graphics.BitmapFactory
import androidx.compose.ui.graphics.ImageBitmap
import androidx.compose.ui.graphics.asImageBitmap
import com.xenyaa.videoshot.core.player.previewLevelOf
import com.xenyaa.videoshot.core.storyboard.Storyboard
import com.xenyaa.videoshot.core.storyboard.StoryboardLevel
import com.xenyaa.videoshot.core.storyboard.StoryboardSpec
import com.xenyaa.videoshot.core.youtube.WatchPage
import com.xenyaa.videoshot.youtube.SheetForbidden
import com.xenyaa.videoshot.youtube.Youtube
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.coroutines.withContext
import java.io.File

/**
 * 詳情頁拖曳預覽的圖（規格第六節「預覽縮圖的來源」）：**拖到哪才下載哪一張 sheet**。
 *
 * 跟第二步的 `StoryboardFrameSource` 不同：那邊一進場就照順序下載整支影片的 sheet（要算指紋收斂），
 * 這裡使用者可能只拖一下，整支下載是白花流量。sheet 放在快取目錄（[dir]），被系統清掉只是下次重新下載。
 *
 * 任何失敗都回 null（預覽泡泡只顯示時間），不丟例外——預覽是錦上添花，不該讓拖曳壞掉。
 */
class PreviewFrames(
    spec: StoryboardSpec,
    private val level: StoryboardLevel,
    private val dir: File,
    private val youtube: Youtube,
    private val refreshSpec: suspend () -> StoryboardSpec?,
    private val io: CoroutineDispatcher,
    private val compute: CoroutineDispatcher,
) {
    private var currentSpec = spec
    private var refreshed = false

    /** 一次只下載一張；拖曳很快時同一張 sheet 不會被同時要好幾次。 */
    private val lock = Mutex()

    /** 最近解開的那一張 sheet。拖曳時大多在同一張裡移動，留一張就省掉反覆解圖。 */
    private var decoded: Pair<Int, Bitmap>? = null

    suspend fun at(sec: Double): ImageBitmap? = try {
        val pos = Storyboard.frameAt(level, sec)
        lock.withLock {
            val sheet = decoded?.takeIf { it.first == pos.sheetIndex }?.second
                ?: loadSheet(pos.sheetIndex)?.also { decoded = pos.sheetIndex to it }
                ?: return@withLock null
            withContext(compute) {
                if (pos.x + pos.width <= sheet.width && pos.y + pos.height <= sheet.height) {
                    Bitmap.createBitmap(sheet, pos.x, pos.y, pos.width, pos.height).asImageBitmap()
                } else {
                    null
                }
            }
        }
    } catch (e: CancellationException) {
        throw e
    } catch (e: Exception) {
        null
    } catch (e: OutOfMemoryError) {
        null
    }

    private suspend fun loadSheet(sheetIndex: Int): Bitmap? {
        val file = File(dir, "M$sheetIndex.jpg")
        val bytes = withContext(io) { file.takeIf { it.exists() }?.readBytes() }
            ?: download(sheetIndex)?.also { b -> withContext(io) { dir.mkdirs(); file.writeBytes(b) } }
            ?: return null
        return withContext(compute) { BitmapFactory.decodeByteArray(bytes, 0, bytes.size) }
    }

    /** 403 時重抓一次 watch page 刷新 spec（同第二步）；整個物件只重抓一次。 */
    private suspend fun download(sheetIndex: Int): ByteArray? {
        repeat(2) {
            try {
                return youtube.sheet(Storyboard.sheetUrl(currentSpec, level, sheetIndex))
            } catch (e: SheetForbidden) {
                if (refreshed) return null
                refreshed = true
                currentSpec = refreshSpec() ?: return null
            }
        }
        return null
    }
}

/**
 * 從 watch page 建預覽來源；沒有 storyboard 回 null（預覽只顯示時間，規格第六節）。
 * 放在 `cacheDir/preview/{videoId}/L{level}/`。
 */
fun previewFramesOf(videoId: String, page: WatchPage, cacheDir: File, youtube: Youtube): PreviewFrames? {
    val spec = page.storyboardSpec?.let { Storyboard.parse(it) } ?: return null
    val level = previewLevelOf(spec) ?: return null
    return PreviewFrames(
        spec = spec,
        level = level,
        dir = File(cacheDir, "preview/$videoId/L${level.level}"),
        youtube = youtube,
        refreshSpec = { youtube.watchPage(videoId).storyboardSpec?.let { Storyboard.parse(it) } },
        io = Dispatchers.IO,
        compute = Dispatchers.Default,
    )
}
```
