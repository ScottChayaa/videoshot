# 階段 15C：瀏覽動線（首頁、Lightbox、詳情、資料夾內容）對齊原型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 首頁、Lightbox、詳情頁、資料夾內容四個畫面的外觀換成原型 `home.html`／`detail.html`／`folder.html` 的樣子（改用階段 15A 的共用元件），縮圖改正方形（設計文件決定 5），並修掉 Lightbox 與詳情頁在深色模式下「圖示幾乎看不見」的缺陷。

**Architecture:** 只動畫面層與兩個 ViewModel 的小欄位；不改資料表、不加新的 SQL。Lightbox 的底色在深淺模式都是固定的近黑色，所以在 `ui/theme/` 補一組固定的「深底上的前景色」（比照 `KindColors` 不隨主題變），取代目前誤用的 `accentInk`（深色模式下它是深色，疊在黑底上就看不見）。正方形縮圖在首頁與資料夾內容共用一個 `ThumbTile`。

**Tech Stack:** Kotlin、Jetpack Compose、Robolectric（`:app:testDebugUnitTest`）、`pnpm compare`。

**Spec:** [`docs/superpowers/specs/2026-10-01-UI對齊原型-design.md`](../specs/2026-10-01-UI對齊原型-design.md)（第六節＝計畫 C；決定 5 正方形、決定 7 Lightbox 純看圖）；視覺來源 `mockups/uiux-v2/styles.css`（「首頁」「區塊」「Lightbox」「分類」段落）與 `home.html`／`detail.html`／`folder.html`；行為依據規格第六節與驗收手冊 §二、§三、§七。

## Global Constraints

- 外觀照原型、行為照驗收手冊與規格（設計文件決定 1）。**不改任何流程**：首頁分頁載入、月份篩選與捲到指定月份、Lightbox 滑動／載入下一頁／一次性提示／刪除後停在下一張、詳情頁聚焦與跳播／編輯 sheet／批次編輯／刪除整支、資料夾內容的子資料夾操作與分頁，全部維持。
- **Lightbox 維持純看圖**（設計文件決定 7）：不加圖資區、頂欄不加日期。
- **紅色只用在破壞性動作**（手冊 §零）。讀取失敗之類的訊息用 `textDim` 或 `warn`，不用 `danger`。
- 間距只用 4／8／12／16／24／32（**例外：首頁與資料夾內容的縮圖格線 2dp**——原型 `.tiles { gap: 2px }` 註明是刻意的例外，「幾乎沒有縫」）；字級 13／15／17／20／24／28；字重 Regular／Medium／Bold；圓角 8／12／全圓。
- 觸控目標最小 44dp；每個可點的東西都有 `focusRing()` 與 TalkBack 名稱。
- 不寫死色碼；Lightbox 用本計畫新增的 `OnDarkColors`，圖上疊字用 `AppTheme.colors.scrim`。
- **非同步狀態更新慣例**（CLAUDE.md，2026-10-02）：讀取回來先算好結果，再 `_state.update { it.copy(…) }`；不要把 suspend 呼叫寫在 `.copy(…)` 參數裡。
- 既有測試不得刪除或弱化；因文字或結構改變而調整的測試，最小幅度修改並註解原因。
- commit message 用繁體中文 `類型(範圍): 描述`，**不加 AI 生成標記**。
- 環境：`export JAVA_HOME=/snap/android-studio/current/jbr ANDROID_HOME=$HOME/Android/Sdk; export PATH=$PATH:$ANDROID_HOME/platform-tools`；Gradle 在 `android/` 下跑。
- **實機會在 10 分鐘無操作後上鎖**：主控在背景跑保持喚醒腳本；任何截圖前先確認 `adb shell dumpsys window | grep isKeyguardShowing` 為 false，上鎖就停下來回報。

```kotlin
package com.xenyaa.videoshot.ui.theme

import androidx.compose.ui.graphics.Color

/**
 * 固定深底（Lightbox 的 `lightboxBg` 深淺模式同值）上的前景色。對應原型 `.lb` 的 `color: #fff`
 * 與 `rgba(255,255,255,…)` 各階。
 *
 * **不放進 [Palette]**：Lightbox 的底色不隨主題變，前景也就不該隨主題變——
 * 階段 15A 之前 Lightbox 用 `accentInk` 當圖示色，深色模式下它是深色，疊在黑底上幾乎看不見。
 */
object OnDarkColors {
    val primary = Color(0xFFFFFFFF)
    val secondary = Color(0xCCFFFFFF)
    val tertiary = Color(0xA6FFFFFF)
    val fill = Color(0x1FFFFFFF)
    val hint = Color(0x8C000000)
}
```
