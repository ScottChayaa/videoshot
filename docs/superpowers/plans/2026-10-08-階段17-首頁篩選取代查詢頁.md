> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 拿掉底部導覽的「查詢」分頁，把「依地點與標籤找圖」搬到首頁：頂欄右上角（日曆鈕左邊）多一顆篩選鈕，點了從下方滑出篩選抽屜，勾選地點與標籤後按【套用】，首頁縮圖牆就只顯示符合的圖。描述查詢與 Gemini 先下架。

**Architecture:** 首頁狀態多一份「已套用的篩選」（地點名稱集合＋標籤名稱集合）；有篩選時，首頁分頁改走 16B 的 `searchByFacets`（依選取大小自動選查法），沒有篩選時照舊走 `homeFeed`。抽屜的候選清單由新的 `StatsDao.filterOptions` 提供（統計表，依全部時間張數排序、依時間範圍過濾，帶別名讓搜尋框能比對）；搜尋框在記憶體裡過濾，不查資料庫。月份選單拿掉張數，選項改成「有圖的月份」：沒篩選時讀 `shot_stat` 的每月總數，有篩選時讀選取項目各自出現過的月份（`shot_stat_by_ref` 索引）。篩選中隱藏月份旁的地點與標籤小膠囊。導覽列的 `Tab.SEARCH` 刪掉；查詢頁的畫面程式（`ui/search/`）、文字查詢、Gemini 的程式**保留不動、不再接到畫面**。

**Tech Stack:** Kotlin、Jetpack Compose、Room 2.8.5（`BundledSQLiteDriver`）、Robolectric（`:app:testDebugUnitTest`）、androidx.test 儀器測試（實機 2107113SG）。

**Spec:** [現行規格](../specs/2026-09-10-videoshot-app-design.md) 第六節（首頁、查詢）、第八節（檢索）、第九節（帳號頁）；驗收手冊 §二、§五、§八。本階段的設計決議見下方（2026-10-08 與 scott 確認），Task 6 寫回規格與手冊。

## 設計決議（2026-10-08 與 scott 確認）

1. **底部導覽從 5 格變 4 格**：首頁、取圖、分類、帳號。拿掉「查詢」。
2. **首頁頂欄右上角**：〔篩選鈕〕〔日曆鈕〕。篩選鈕用 `VsIcons.Filter`，有篩選時跟日曆鈕一樣用 `active = true` 的樣子（主色淺底圓形＋主色圖示）。
3. **篩選抽屜**（`ModalBottomSheet`）：
   - 標題列「篩選」，右上角【清除篩選】：清掉抽屜裡的勾選（草稿），**要按【套用】才生效**。
   - 「地點」區：標題右邊一個搜尋框；下面是地點小膠囊（切換型 `VsTagChip`，`isToggle = true`），可多選。「標籤」區同樣結構。
   - 搜尋框打字即時過濾，比對名稱與別名（打「礁溪」也找得到「宜蘭礁溪」）。
   - 清單只列**目前時間範圍內有圖**的項目，依**全部時間**的張數排序，小膠囊不顯示張數。已勾選但不在時間範圍內的項目照樣列在最前面（不會被偷偷取消）。
   - 每一區預設只列前 **50** 個，下面【顯示全部（N）】展開；搜尋框有字時列出全部符合的。理由：地點與標籤可能上千個，一次畫上千顆小膠囊會讓抽屜開啟卡頓。
   - 底部【套用】（主色按鈕）：把草稿變成已套用的篩選並關閉抽屜。關掉抽屜沒按【套用】＝草稿作廢。
   - 多選是**任一個符合**（地點與標籤之間、彼此之間都是 OR）。
4. **篩選中的首頁**：縮圖牆只顯示符合的圖，月份分組與吸頂標題照舊；**月份旁的地點與標籤小膠囊隱藏**；不顯示「N 張」；點圖開 Lightbox，左右滑的範圍是篩選後的清單。換了篩選捲回頂端。0 張時空狀態「沒有符合篩選的收藏」＋【清除篩選】（這顆會直接清掉已套用的篩選）。
5. **月份選單（日曆鈕）拿掉每個月的張數**，只列有圖的月份；篩選中只列「選取項目在那個月有圖」的月份。
6. **沒篩選時，月份旁的小膠囊點了**：直接在首頁套用「只篩這一個」（時間範圍不變），不再跳到查詢頁。
7. **下架**：描述查詢（含規則式與 Gemini 解析的畫面入口）；帳號頁「查詢 · Gemini 金鑰」那一列**隱藏**（選單剩 6 列）。`ui/search/`、`query/`、repo 的 `searchByQuery`／`queryVocabulary`、`AccountSection.GEMINI` 與 `GeminiKeyScreen` **都保留**，只是沒有入口；日後要重新開放時接回去即可。
8. **地點或標籤改名、合併、刪除之後**（`labelsChanged`），首頁已套用的篩選**清空**：舊名稱可能已經不存在，留著會查不到東西又看不出原因。

```kotlin
    /**
     * 首頁篩選抽屜的候選（階段 17）：全部地點與標籤，依**全部時間**張數排序；`upToMonth` 只過濾（同 [candidates]）。
     * 跟 [candidates] 的差別：不設上限、帶別名（抽屜的搜尋框要比對）。
     */
    @SkipQueryVerification
    @Query(
        """
        SELECT COALESCE(p.name, t.name) AS name,
               g.kind AS kind,
               CASE g.kind WHEN 1 THEN 'other' ELSE t.kind END AS tag_kind,
               COALESCE(p.aliases, t.aliases) AS aliases
        FROM shot_stat_total g
        LEFT JOIN place p ON g.kind = 1 AND p.id = g.ref_id
        LEFT JOIN tag t ON g.kind = 2 AND t.id = g.ref_id
        WHERE g.kind IN (1, 2) AND g.cnt > 0
          AND (:upToMonth IS NULL OR EXISTS (
                SELECT 1 FROM shot_stat s
                WHERE s.kind = g.kind AND s.ref_id = g.ref_id AND s.month <= :upToMonth AND s.cnt > 0))
        ORDER BY g.cnt DESC, name, g.kind
        """
    )
    suspend fun filterOptions(upToMonth: String?): List<FilterOptionProjection>

    /** 有圖的月份，新到舊（月份選單；不帶張數，階段 17 設計決議 5）。 */
    @SkipQueryVerification
    @Query("SELECT month FROM shot_stat WHERE kind = 0 AND ref_id = 0 AND cnt > 0 ORDER BY month DESC")
    suspend fun allMonths(): List<String>

    /** 任一選取的地點或標籤有圖的月份，新到舊。走 `shot_stat_by_ref (kind, ref_id, month)`。 */
    @SkipQueryVerification
    @Query(
        """
        SELECT DISTINCT month FROM shot_stat
        WHERE cnt > 0 AND ((kind = 1 AND ref_id IN (:placeIds)) OR (kind = 2 AND ref_id IN (:tagIds)))
        ORDER BY month DESC
        """
    )
    suspend fun monthsOf(placeIds: List<Long>, tagIds: List<Long>): List<String>
```

```kotlin
package com.xenyaa.videoshot.ui.home

import com.xenyaa.videoshot.data.repo.model.FilterOption

/** 已套用到首頁的篩選（階段 17）：地點與標籤名稱，**任一個符合**即顯示。空＝沒有篩選。 */
data class HomeFilter(val places: Set<String> = emptySet(), val tags: Set<String> = emptySet()) {
    val isEmpty: Boolean get() = places.isEmpty() && tags.isEmpty()
    val size: Int get() = places.size + tags.size
}

/**
 * 篩選抽屜開著時的草稿：按【套用】才變成 [HomeFilter]，關掉抽屜就丟掉（設計決議 3）。
 * `query`／`expanded` 的 key：true＝地點區、false＝標籤區。
 */
data class FilterDraft(
    val places: Set<String>,
    val tags: Set<String>,
    val query: Map<Boolean, String> = mapOf(true to "", false to ""),
    val expanded: Set<Boolean> = emptySet(),
) {
    fun isSelected(option: FilterOption) = if (option.isPlace) option.name in places else option.name in tags
}

data class FilterSection(val shown: List<FilterOption>, val hiddenCount: Int)

/** 抽屜每一區實際要畫哪些小膠囊（純函式，畫面與測試共用）。 */
object FilterLists {
    /** 未展開、沒有搜尋字時每區最多畫幾個——上千顆小膠囊一次畫出來會讓抽屜開啟卡頓。 */
    const val COLLAPSED_LIMIT = 50

    fun visible(options: List<FilterOption>, isPlace: Boolean, draft: FilterDraft): FilterSection {
        val pool = options.filter { it.isPlace == isPlace }
        val selected = if (isPlace) draft.places else draft.tags
        val missing = (selected - pool.map { it.name }.toSet()).sorted()
            .map { FilterOption(it, isPlace, "other", emptyList()) }
        val query = draft.query[isPlace].orEmpty().trim()
        if (query.isNotEmpty()) {
            val hit = (missing + pool).filter { o ->
                o.name.contains(query, ignoreCase = true) || o.aliases.any { it.contains(query, ignoreCase = true) }
            }
            return FilterSection(hit, 0)
        }
        val all = missing + pool
        if (isPlace in draft.expanded || all.size <= COLLAPSED_LIMIT) return FilterSection(all, 0)
        return FilterSection(all.take(COLLAPSED_LIMIT), all.size - COLLAPSED_LIMIT)
    }
}
```
