## 教訓

- **「有 storyboard」不等於「有可挑的縮圖」**：要看層級。很短的片只有 L0，取圖精靈不用它，所以第二步是空的。驗「接得上」要真的走到下一步看畫面，不能只看 API 回了東西。
- **關 Wi-Fi 不等於沒網路**：手機的行動數據設定讀起來是 0，實際還走得到行動網路；測沒網路要 Wi-Fi 與行動數據一起關，並先 `ping` 確認真的斷了。
- **開發測試版有兩個桌面圖示**：`monkey -p` 可能打開「元件總覽」而不是主畫面，要用 `am start -n com.xenyaa.videoshot/.MainActivity`。
- **`adb shell run-as … sh -c "…"` 的引號會被拆開**：整串要用單引號包在 `adb shell "…"` 裡面。
