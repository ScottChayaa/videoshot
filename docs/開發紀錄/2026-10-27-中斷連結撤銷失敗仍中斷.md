# 換 Cloud 專案後【中斷連結】永遠失敗

[← 回索引](README.md)

- **日期**：2026-10-27
- **狀態**：修正並實機驗收

## 為什麼

- 2026-10-26 Google Cloud 專案從共用的 `mypass-470608` 換成獨立的 `videoshot`（規格第十節）。手機上的 Drive 授權是舊專案的 OAuth client 給的，那個 client 已經刪掉。
- 按【中斷連結】時 app 先呼叫 `AuthorizationClient.revokeAccess`，撤銷成功才在本機清掉連結。用新專案去撤舊授權，GMS 回 `ApiException: 10: No access token was returned`，所以每次都顯示「中斷連結失敗，請確認網路後再試一次」，也就沒辦法重新連結到新專案。

## 做了什麼

- `AppContainer` 的 `unlink()`：撤銷授權失敗（取消除外）只記一筆 `Log.w("VsGoogleAuth", …)`，照樣清掉本機的連結帳號與頭像快取。Google 那邊殘留的授權沒有害處，使用者可以在 Google 帳戶的「第三方應用程式和服務」自己移除。

## 決議

- 撤銷是「盡量做」，本機中斷才是使用者要的結果（Claude 的決定）。另一個做法是撤銷失敗時問使用者要不要強制中斷，多一個對話框，沒採用。

## 驗收

- `:app:testDebugUnitTest --tests '*Account*'` 全綠（`AppContainer` 沒有單元測試，這段只靠編譯與實機）。
- **實機（2107113SG，2026-10-27）**：
  - 【中斷連結】成功；log 有 `撤銷 Google 授權失敗，仍在本機中斷連結`，原因是上面的 `ApiException: 10`。
  - 重新連結 mmx112945@gmail.com：出現新專案的 Drive 授權畫面（`NEED_REMOTE_CONSENT` 後拿到權杖），沒有「尚未驗證」警告。
  - 【立即備份】→「上次備份：剛剛」，`last_backup_at` 寫入；備份上傳到新專案的 appDataFolder。
- 同一天 Cloud Console 的「目標對象」改成**正式版**（實際運作中），授權不會 7 天就失效。
