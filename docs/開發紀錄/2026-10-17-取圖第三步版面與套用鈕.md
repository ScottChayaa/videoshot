# 取圖第三步：縮圖牆比照第二步、【套用】移到抽屜標題列

[← 回索引](README.md)

- **日期**：2026-10-17
- **狀態**：完成並實機驗收（版面；【套用】【完成】沒在實機按，見下方）

## 做了什麼

批次編輯圖資跟第三步共用同一個畫面，以下除了「全部填完才能完成」都一起改。

- **縮圖牆**：每列 4 張正方形、左右貼齊螢幕、格線很細（同第二步）；勾選中只在左上打勾、不畫主色框；還沒套用的不再壓暗，套用過的保留右上綠勾
- **快捷列**：拿掉【全不選】，剩【全選】【反選】【未填 N】
- **抽屜標題列**：「套用到已選的 N 張」改成「照片詳細資訊」（只勾一張時旁邊照舊帶時間），右邊放小顆的【套用】（同快捷列的小鈕，視覺 30dp），整列約 52dp。有改動時【套用】換成主色底
- **底部主按鈕固定是【完成】**：原本在【完成】與【套用到 N 張】之間切換。還有沒套用的修改時按【完成】，先套用再結束
- **取圖精靈要「未填 N」歸 0 才能【完成】**：原本是提醒「還有 N 張沒填資料，仍要完成嗎？」但不阻擋；現在按鈕停用。改了欄位還沒按【套用】也不算。批次編輯不受限制
- **拿掉底部列上方的「將更新：…　其他欄位維持各張原值」提示行**：動過的欄位標題本來就會變主色並亮點
- **沒改欄位也能按【套用】**：等於照現值確認，一樣打綠勾、值不變。不然只想沿用預設時間的那幾張永遠填不完
- **標籤區**：由上到下是標題 → 已加的標籤 → 輸入框＋【加入】→ 用過的標籤（同照片編輯抽屜）。已加的標籤改成照片編輯抽屜的樣式（中性淺底、種類圖示、尾端 ✕），抽成共用元件 `VsRemovableTag`
- **建議小膠囊**：拿掉「用過的地點」「用過的標籤」小標；建議標籤的圖示改成依種類（原本全部畫成「其他」的 ◇），順序改成用過越多張的排越前面（同照片編輯抽屜）

## 決議

- scott 提出七項改動；這幾件是 scott 從選項中決定的：
  - 主按鈕固定【完成】、有修改時自動套用，而且「須全部完成填寫才能按下」
  - 已套用記號留右上綠勾、拿掉壓暗
  - 批次編輯一起改
- 第一版做完後 scott 再調三點：標題列太高 → 【套用】改小鈕；【完成】改成「未填」歸 0 才啟用（拿掉「修改涵蓋剩下的也算」）；拿掉「將更新」提示行
- 「全部填完才能完成」只加在取圖精靈：批次編輯只寫回套用過的那幾張，要求全填就沒辦法只改其中幾張
- 為了讓「全部填完」做得到，【套用】在沒改欄位時也有作用（照現值確認）
- 取圖精靈原本的「仍要完成」提醒框留在程式裡，當 ViewModel 的防線；正常操作走不到
