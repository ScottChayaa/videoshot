# 標籤不分種類，統一成 `#`

[← 回索引](README.md)

- **日期**：2026-10-23
- **狀態**：完成並實機驗收

## 為什麼

- 標籤原本分人物／動物／主題／其他四種，各有圖示與顏色，標籤管理可以改種類、編輯抽屜新打標籤時要選種類
- scott 決定分類沒用了：統一成社群上常見的 `#`，種類整個拿掉，連資料庫欄位一起刪

## 做了什麼

- **畫面**
  - 所有標籤小膠囊都是 `#`＋紫色（沿用原本「主題」的圖示與顏色）；地點的定位針＋藍色不變
  - 標籤管理：每列圖示是 `#`，副標從「人物 ・ 3 張」改成「3 張」
  - 標籤編輯抽屜：拿掉「顯示圖示」那一排四選一，只剩名稱、別名、刪除、合併、儲存
  - 照片的詳細資料抽屜：新打的標籤加入後不再跳出「「名字」是：人物 動物 主題 其他」那一列
- **資料庫**：`library.db` 版本 3 → 4，遷移只有一句 `ALTER TABLE tag DROP COLUMN kind`；舊備份還原時一樣自動升上來，標籤一個不少
- **刪掉的程式**：`TagKind`（`parseAliases` 搬到 `core/tags/Aliases.kt`）、`TagNameKind`、`tagsWithKindOfShot`、`DetailsPatch／ShotPatch.newTagKinds`、
  `MonthFacet／FilterOption.tagKind`、`TagUsage.kind`、`TagEditor.kind`、`NewTagKindRow`、`ChipKind` 的人物／動物／主題／其他四種（剩 `PLACE`、`TAG`）、
  `VsIcons.Pet／OtherKind`（`Topic` 改名 `Hash`）、`KindColors` 的四個標籤色（剩 `place`、`tag`）
- **順手簡化**（因為只剩一種標籤）：`VsChipPager` 的 `kindOf: (Int) -> ChipKind` 改成 `kind: ChipKind`；`VsRemovableTag` 拿掉 `kind` 參數；
  標籤候選從「名稱＋種類」變成單純的名稱清單
- **假資料**：`export-seed.mjs` 只匯出標籤名，`mock-seed.json` 重新產生；匯入時不再補改種類

## 驗收

- `:core:test`、`:app:testDebugUnitTest` 全綠（1404 個）；`:app:compileDebugAndroidTestKotlin` 編譯過
- 種類相關的測試刪除或改寫：編輯抽屜改測「新標籤加入後不出現種類選擇」、標籤管理改測「圖示是標籤色、抽屜沒有種類選擇」
- 儀器測試新增 `MigrationFromV1Test.標籤不再有種類欄位_標籤一個不少`（v1 檔案一路升到 v4）
- **實機（2107113SG）**
  - 儀器測試用 `am instrument` 跑：`OK (288 tests)`，含新加的那一條
  - scott 的圖庫（v3、175 張、24 個標籤，先備份到電腦）裝新版後打開：升到 v4、張數與標籤數不變、`tag` 只剩 `id／name／aliases`、`integrity_check` ok、沒有閃退
  - 截圖看過：首頁月份標籤、篩選抽屜、Lightbox 標籤列、詳細資料抽屜（打新標籤 `vstest` 加入後直接是 `#`、沒有種類選擇列；按【取消】沒存）、
    標籤管理清單（`#`＋「N 張」）、標籤編輯抽屜（沒有種類選擇）、合併目標清單。走完再讀一次圖庫：仍是 175 張、24 個標籤
