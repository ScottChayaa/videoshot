## 15A：共用元件層與驗收工具（10-01）

**做了什麼**
- `ui/common/` 共用元件：`VsTopBar`（`TopBarIconButton`／`TopBarNav`／`TopBarTitle`）、`VsBottomNav`（`avatarInitialOf`）、`VsTagChip`（`ChipKind`／`ChipSize`）、`VsButton`（`ButtonVariant`）、`VsListRow`、`VsEmptyState`、`VsActionDock`、`VsStepIndicator`、`VsUnderlineTabs`、`VsToolbarPill`（`PillStyle`）、`VsHintCard`；主題補 `KindColors`、`Spacing.topBarHeight`，圖示補 `MapPin`、`Film`
- 各畫面換成共用頂欄（固定 60dp＋1dp 分隔線，標題 20 粗體）；底部導覽的「取圖」格是主色實心方塊、帳號格連結後顯示頭像字母
- **開發測試版專用工具**（`app/src/debug/`，已用 release APK 的 dex 驗證不含）：元件總覽頁、假資料匯入（`pnpm seed` ＋ `SeedReceiver`）、`pnpm compare` 原型與實機對照截圖
- 裁定：步驟列每段最小高 44dp（比原型鬆）；假資料是 11 支影片；假資料的加入時間用秒

**驗收**：JVM 846 個全綠（乾淨 worktree 重跑一致）；儀器測試 `OK (210 tests)`。

**實機發現兩個卡住問題，10-02 查出根因並修正**（兩者不同源，也都跟資料庫無關）：
1. **詳情頁永遠停在「正在載入…」**（commit `4832d60`）：狀態寫回蓋掉已載入的值，同類寫法另有五處一併修掉。由此訂下慣例：非同步讀取回來先算結果，再 `_state.update { it.copy(…) }`。細節見問答 [非同步讀取寫回畫面狀態要注意什麼？](../問答/非同步讀取寫回狀態.md)。階段 9 記的「偶爾卡 16 秒」就是這個。
2. **白畫面不動**（commit `7e1eb2c`）：MIUI「背景 app 停用動畫」吞掉 Compose 的第一個幀請求。修法 `FrameStallGuard`。正式版使用者也可能遇到。細節見問答 [為什麼 app 偶爾白畫面不動？](../問答/開app白畫面不動.md)。修正後 JVM 854 個。

## 15C：首頁、Lightbox、詳情、資料夾內容對齊原型（10-03）

**做了什麼**
- 首頁與資料夾內容縮圖改**正方形**（格線 2dp）；月份標籤小膠囊帶種類圖示與顏色，觸控區 44dp
- Lightbox 改原型樣式（關閉／⋯ 頂列、滑動提示、主按鈕＋加入分類／分享兩顆圖示鈕）
- 詳情頁：播放器 → 圖資卡 →「這支影片的收藏（N）」網格（右上鉛筆鈕、聚焦那張有框）
- 資料夾內容頂欄下方加麵包屑（2026-10-12 已拿掉），子資料夾改直向清單列
- 新增 `OnDarkColors`（固定深底上的前景色）與 `ThumbTile`；縮圖抓不到的預留圖換新樣式
- 最終審查修正：`VsTagChip` 分動作型（預設）與切換型（`isToggle = true`）——原本可點的都被 TalkBack 唸成「未勾選，核取方塊」；月份標籤種類對應抽成 `chipKindOf`

**驗收**：JVM 941 個全綠（修正前已用乾淨 worktree 重跑）；儀器測試只重跑了動到的 `LibraryRepoFeedTest`＋`SearchRepoTest`（`OK (25 tests)`）。`pnpm compare` 首頁／Lightbox／詳情／資料夾內容結構與原型一致。

**教訓**
- **Lightbox 底色固定近黑，但圖示原本用 `accentInk`**（深色色盤裡也是近黑），深色模式下幾乎看不見 → 改用固定的 `OnDarkColors`。
- **`pnpm compare` 抓到真 bug**：月份標籤小膠囊全部是「其他」圖示。`ShotDao.monthFacets` 的 `kind` 只有 `place`／`tag`，畫面拿它查標籤種類永遠落到「其他」→ SQL 另外帶出 `tag.kind`、`MonthFacet` 加 `tagKind`。單元測試看不出來（假資料直接組 `MonthFacet`），也代表計畫寫的「不加新的 SQL」不成立。
