# app 圖示換成「書籤那一秒」：書籤裡的播放鍵

[← 回索引](README.md)

- **日期**：2026-11-18
- **狀態**：完成並實機驗收，網站已部署（單色主題圖示未實機；Google 品牌頁的標誌還沒換）

## 為什麼

scott 重新設計了 logo（標誌套件 v1.0），取代 2026-11-03 的「浮島」。意思是「把讓你停下來的那一秒存成書籤」：書籤裡是播放鍵，底部缺口是 V。

## 做了什麼

- 標誌套件整包放進 repo 的 **`brand/`**（符號、橫式／直式圖文組合、字標、app 與網頁圖示、應用示意簡報、使用規範 PDF），之後 logo 一律以這裡為準
- app 桌面圖示：暖炭 `#1D1A17` 底、暖黃 `#FFBE3D` 書籤（`ic_launcher_background.xml`、`ic_launcher_foreground.xml`）；路徑照 `brand/05-app-and-web-icons/app-icon.svg`，符號佔比跟套件一樣（圖示邊長的 0.74 倍範圍內），換算到桌面看得到的中間 72
- 單色主題圖示（`ic_launcher_monochrome.xml`）：同一個符號，白色
- 網站 `site/public/logo.svg` 換成 `app-icon.svg`
- 同一天字標從 Poppins Medium 換成 **Nunito Bold**（字距 −0.5%，V–i 另收緊 0.1 em）：橫式、直式、字標所有顏色版本的 SVG 與 2000 寬 PNG，以及應用示意簡報裡內嵌的字標與第 3、4 頁截圖。字高、基線、邊界照舊，寬度跟著變窄。使用規範 PDF 原本沒有原始檔，改用 HTML 重建（`brand/VideoShot-brand-guidelines.html`，直接引用套件的 SVG）再輸出成 A4 一頁的 PDF，內容沿用原版、字標說明改成 Nunito
- 網站照標誌套件改版（`site/public/`）：首頁頂端是暖炭色主視覺＋深色版橫式 logo，內容區奶油色底、功能介紹改成四張圓角卡片，連結用暖黃底線，小標前放小書籤；隱私權頁頂端換成暖炭色窄版標頭（小 logo 可回首頁）。字型 Nunito＋Noto Sans TC（Google Fonts）；分頁圖示改用套件的 favicon.ico／favicon.svg（32 px 以下用的小尺寸版）與 apple-touch-icon，`theme-color` 設成暖炭色，舊的 `logo.svg` 刪除。頁面上的名稱改成 VideoShot（Google Drive「管理應用程式」路徑那句照 OAuth 名稱維持小寫）。本機 `wrangler dev` 看過桌面與手機寬度，之後 `wrangler deploy` 上線，線上首頁、隱私權頁與各圖示檔都確認可取得（舊的 `/logo.svg` 已是 404）
- 網頁上的橫式 logo 符號比文字高太多（套件預設符號約字高 2.4 倍），scott 看過 2.4／1.8／1.4／1.1 倍的預覽後選 1.8 倍：新增橫式精簡版 `brand/02-horizontal/logo-horizontal-compact-*`（各顏色 SVG＋PNG，文字大小、間距、左右邊界照預設版），網站首頁與隱私權頁標頭改用它，字的大小不變
- 舊版刪除、留在 git 歷史：mockups 的圖示配色頁（`mockups/logo/`，只為浮島調色用）與它在 mockups 首頁的連結

## 驗收

- `assembleDebug` 通過
- 用 Chrome 把前景向量換算成 SVG，裁成圓形與圓角方形，跟套件的 `app-icon.svg` 並排比對，形狀與比例一致
- scott 2026-11-18 驗收 app 圖示 OK
- **實機（2107113SG，小米桌面）**：`adb install -r` 覆蓋安裝後滑到第四頁截圖，videoshot 與元件總覽兩個圖示都是暖炭底暖黃書籤，播放鍵在桌面大小下清楚
- **網站**：在 `site/` 執行 `wrangler deploy` 部署，線上的 `logo.svg` 確認是新圖示（首頁與隱私權頁的分頁圖示都用它）。部署前線上還是「回到那一刻」，浮島那幾次只改了 repo、沒部署過；這次 wrangler 也把 `privacy.html` 當成有修改的檔案一起上傳，線上內容現在跟 repo 一致
- Android 13 單色主題圖示沒在實機開過（見[已知缺口](../已知缺口.md)）
