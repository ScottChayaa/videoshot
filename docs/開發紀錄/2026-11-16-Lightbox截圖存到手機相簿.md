# Lightbox【分享】換成【截圖】，存到手機相簿

2026-11-16 scott 要求：Lightbox 底部的【分享】拿掉，改成從目前的影片取一張圖、存回手機相簿。

## 做了什麼

- 底部動作列第四顆圖示鈕從【分享】換成【截圖】，位置不變。圖示一開始用取圖第二步的剪刀，scott 看過六個候選後改成照片加向下箭頭（Lucide `image-down`）：最能表達「存到手機相簿」，剪刀容易被當成剪輯。
- 按下去時：
  - 大圖已經是影片定格的清楚畫面，就把那一格以**影片原尺寸**的 JPEG 存進手機相簿 `Pictures/videoshot/`，
    檔名 `{videoId}_{秒}s.jpg`（同名時相簿自己接編號）。
  - 大圖還是縮圖（影片還沒載好、或抓不到），就不存，跳「影片畫面還沒出來，稍等再截」。
  - 寫入相簿失敗（空間不足等）時跳「存到相簿失敗，請再試一次」。
- 成功不跳文字，改成動畫（scott 看過提示條蓋住按鈕列後要求）：手機震一下，影片那一格閃白光（只蓋畫面、不蓋左右留白），
  縮成圓角白邊小卡沿弧線飛進【截圖】鈕（約 0.45 秒），鈕彈一下、圖示換成 ✓ 一秒。
  影片層是 WebView 不能拿來縮放，飛的是截到的那張圖，疊在最上面、飛完拿掉。
- Lightbox 的提示條（失敗訊息、抽屜存檔的「已儲存」等）改疊在動作列上方，會暫時蓋住兩行描述，按鈕一直按得到。
  提示條放頂部會蓋住日期、地點、標籤，只把動作列往上推會讓版面跳，所以都沒採用。
- 截圖沿用取圖第二步的同一段 JS（canvas 畫出 `<video>` 那一格），只是不縮成 320×180、不判黑畫面。
- 存相簿沿用剪輯成品存影片的那一套流程（Android 10 起不要權限；9 以下用既有的寫入權限），多一個存圖片的入口。
- 系統分享面板、分享網址 `https://youtu.be/{videoId}?t={秒}` 與分享圖示一起刪掉。

## 改成最高畫質

scott 要截圖用最高畫質。實機量過，原本截到的不是影片的最高畫質：

- 截圖存的是播放器正在播的那一格，畫質是 YouTube 依播放器大小自動挑的。釣魚那支直片在 YouTube 上最高 1080p，
  Lightbox 只給到 720p，截出來 720×1280。
- 現在按【截圖】時先把播放器的畫質固定在這支影片可選的最高一級、跳回同一個時間點，
  等畫面尺寸真的換過去再截；最多等 3 秒，等不到（網路慢）就截當下的畫質。已經是最高畫質時不用等。
- 只在按【截圖】時才切，平常滑 Lightbox 不多耗流量；切過之後同一張再截就不用再等。
