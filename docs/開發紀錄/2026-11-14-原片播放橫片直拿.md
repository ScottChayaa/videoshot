# 原片播放：橫的影片維持直拿，按【全螢幕】才轉橫

[← 回索引](README.md)

2026-11-14　完成並實機走查，待 scott 驗收

## 做了什麼

- 橫的影片進原片播放**不再一進來就轉橫向**：手機維持直拿，影片寬滿、16:9、上下置中，標題列一直在畫面頂端，
  狀態列與導覽列照常顯示（黑底上換白圖示，離開時還原）。
- 影片正下方一顆膠囊鈕【全螢幕】（翻轉圖示＋字；圖示照 scott 給的 TikTok 截圖重描：直立手機、右下半透明的橫倒手機、右上彎箭頭帶實心三角，線寬 1.5），按下轉橫向全螢幕；控制層右下的【離開全螢幕】或系統返回鍵回到直拿，
  再按一次返回才回 Lightbox。轉向是同一個播放器原地放大，影片接著播、不重載。
- 直的影片不變：一進來就全螢幕、鎖直立，返回直接回 Lightbox。
- 播放器的「原片播放模式」從「一進來就鎖全螢幕」改成「讀到影片寬高時告訴原片播放畫面是不是橫的」，方向與返回都由原片播放畫面決定；
  取圖第二步與 Lightbox 片段的全螢幕行為沒動。

## 決議（scott，2026-11-14）

- 原話：「如果是橫的，則維持直式手拿的方式顯示播放，然後影片播放下方有個全螢幕圖示，像是 tiktok 那樣的翻轉橫屏播放的圖示」。
- 按鈕是膠囊＋圖示＋「全螢幕」字、在影片下方 24dp。圖示 scott 看過幾版後選定：要像 TikTok 的翻轉圖示、箭頭是實心三角、線條細一點、右側橫螢幕貼近手機、箭頭不碰到橫螢幕。
