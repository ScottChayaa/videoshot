# 原片播放加【截圖】

2026-11-16 scott 要求：原片播放的【聲音】鈕旁邊放一顆截圖，直拿和全螢幕都要有，效果同 Lightbox 的【截圖】。

## 做了什麼

- 控制層右下【聲音】鈕左邊多一顆【截圖】，圖示同 Lightbox（框加剪刀）。直拿（橫的影片）、直的影片全螢幕、橫的影片全螢幕都有；
  取圖第二步的播放器沒有。
- 按下時：手機震一下 → 影片停在按下的那一格 → 切到這支影片的最高畫質、截那一格 → 存進手機相簿 `Pictures/videoshot/{videoId}_{秒}s.jpg`
  → 原本在播的接著播。動畫沿用 Lightbox：閃白光、小卡沿弧線飛進按鈕、鈕彈一下、圖示換成 ✓ 一秒。
- 截不到跳「截不到畫面，請再試一次」，寫入相簿失敗跳「存到相簿失敗，請再試一次」。
- 「切最高畫質再截」原本寫在 Lightbox 的播放器裡，搬到截圖模組讓兩邊共用，行為不變（最多等 3 秒，等不到就截當下畫質）。

## 驗收

- 單元測試全跑：1740 個只有 1 個失敗，是之前就壞的剪輯測試 `AppRootClipTest.播放中按刪除_刪掉畫面上正在播的那一段`，跟這次無關。
- 實機：見下方。

## 換畫質時黑一下

- 第一次走查發現：第一次截某支影片時要切到最高畫質，影片畫面會**黑一下**（全螢幕按下 0.4 秒時整片黑，約半秒後恢復）。
  Lightbox 第一次截圖也一樣，只是本來就停著、比較不明顯。
- 修法：要切畫質時，先用當下的畫質截一張蓋在影片上（原片播放蓋在控制層下面），等它真的畫上畫面才切，高畫質那一格換好就拿掉。
  已經是最高畫質時不截、不蓋。Lightbox 與原片播放共用這一套。
- 修完實機：橫片全螢幕重開後第一次截，按下後連拍六張都沒有黑畫面（平均亮度 76～118，修之前是整片黑），總長從 02:24 變 02:25（確實換過串流），
  存下 1920×1080；回 Lightbox 第一次截，連拍也沒有黑，存下 1920×1080。測試存的圖已刪掉。

## 已知限制

- 播放中控制層 3 秒沒動作會收起，要先點一下叫出來才按得到【截圖】（同【聲音】）。
