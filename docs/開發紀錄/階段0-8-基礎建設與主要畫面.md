## 決議

階段 0 的結論已寫回規格（第二節第 5、7 點、第五節、第十一節、第十二節）。三個對實作影響最大的：

- **截圖用 JS canvas**，不是 PixelCopy
- **播放器依 `playabilityStatus.playableInEmbed` 決定載入方式**，而且 embed 必須模擬點擊才會播
- **InnerTube 不帶 storyboard spec**，縮圖回填只能走 watch page

## 驗收

- **首頁與 Lightbox（手冊 §二、§三）**：年月分組、月份篩選、封面降級、刪除後自動停在下一張、縮圖抓不到時的降級預留圖。做法是把種子資料直接寫進 `library.db` 再開 app。
- **手冊 §零（2026-09-18）**：
  - 平板寬度加欄：`wm size 1280x800` ＋ `wm density 240`（853dp）→ 5 欄，驗完 `wm size reset`／`wm density reset`
  - TalkBack 要唸的名稱：`uiautomator dump` 看每張縮圖都有「片段縮圖 MM:SS」或描述（只驗名稱，沒驗唸讀順序）
  - 實體鍵盤焦點框：首頁縮圖、底部導覽、Lightbox 的關閉與動作鈕都看得到框
- **取圖精靈第一次完整走過（2026-09-17）**：貼 `youtu.be/aqz-KE-bpKQ` → watch page 抓到、storyboard 裁出真圖、收斂回報「119 張候選、隱藏 9 張」→ 挑 3 張 → 第三步自動帶入上傳日期 2014-11-10 → 【完成】→「還有 3 張沒填資料」提醒但不阻擋 → 回首頁並捲到 2014 年 11 月。
