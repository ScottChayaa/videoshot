## 每篇的寫法

- 檔名：階段用 `階段N-名稱.md`，其他用 `YYYY-MM-DD-名稱.md`
- 第一行 `# 標題`，第二段 `[← 回索引](README.md)`，再來是日期、狀態、計畫或 commit
- 四段（沒有就省略）：**做了什麼**（使用者看得到的）、**決議**（誰決定的）、**驗收**（完成時的測試數、實機驗了什麼）、**教訓**
- 沒做完、沒驗到、刻意擱置的寫進[已知缺口](../已知缺口.md)，這裡只放連結
- 寫完在上面的表格最上面加一列
