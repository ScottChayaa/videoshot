# 帳號頁 hero 從整塊夕陽橘改成淡杏底、夕陽只留在頭像

[← 回索引](README.md)

- **日期**：2026-10-25
- **狀態**：完成並實機驗收（已連結 Google 的樣子未實機）

## 為什麼

- 同一天換上[夕陽海灘色系](2026-10-25-夕陽海灘色系.md)後，scott 覺得帳號頁頂部那整塊陶土 → 焦糖橘漸層太搶眼：全 app 其他地方都是白沙底＋深海藍，只有這裡是一大塊高彩度暖色

## 做了什麼

- **hero 底**：整塊夕陽漸層 → 由上往下的淡杏色漸層（`hero1` 混 14% 進底色 → 底色），下緣跟頁面底色接得無縫
- **頭像**：半透明白底＋白框 → 夕陽漸層（`hero1` → `hero2`）實心圓，白色字母／人形圖示不變
- **名稱與 Email**：白字 → 一般深色字（`text`／`textDim`）
- `OnDarkColors` 拿掉只給 hero 頭像用的 `avatarFill`、`avatarRing`
- 色票欄位沒有增加：淡杏色是從 `hero1` 算出來的，所以新年色系的 hero 也會自動變成淡紅底＋紅金頭像；`hero2` 仍是 Material 的 `secondary`，不受影響

## 決議

- 2026-10-25 scott：四個方向（深海藍、淡沙色、壓暗陶土，加上現況）選了**淡沙色**：夕陽海灘的感覺留在頭像上，視線落在名字而不是色塊
- 第一版用斜向漸層，左下角淡不完、跟下方底色之間有一條邊，改成垂直漸層
